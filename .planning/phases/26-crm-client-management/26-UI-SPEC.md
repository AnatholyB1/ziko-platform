## Spacing Scale

Standard 8-point scale. All values are multiples of 4.

| Token | Tailwind | Value | Usage |
|-------|----------|-------|-------|
| xs | `gap-1`, `p-1` | 4px | Icon gaps, chip internal padding |
| sm | `gap-2`, `p-2` | 8px | Chip group gap, inline element spacing |
| md | `p-4`, `gap-4` | 16px | Default element padding, table cell px |
| lg | `p-6`, `gap-6` | 24px | Card padding (existing: `p-8` = 32px on WelcomeCard) |
| xl | `p-8` | 32px | Card outer padding (match WelcomeCard pattern) |
| 2xl | `py-12` | 48px | Section vertical breaks |
| 3xl | `py-16` | 64px | Empty state vertical padding (match InvitationsTable `py-16`) |

**Exceptions:**
- Table row cell: `py-3 px-4` (12px / 16px) — match InvitationsTable pattern exactly
- Table header: `py-3 px-4` with `text-xs tracking-wide uppercase` — match InvitationsTable
- Nav item height: `h-11` (44px) — match NavItem touch target
- Modal: `p-8 max-w-md` — match RevokeConfirmModal pattern exactly
- Sidebar width: `w-60` (240px) — fixed, match CoachSidebar
- Sticky comparison button: minimum `h-12` (48px) for touch affordance

## Typography

Four roles, two weights maximum. All sizes are in px / rem equivalents via Tailwind.

| Role | Tailwind | Size | Weight | Line Height | Usage |
|------|----------|------|--------|-------------|-------|
| Display | `text-2xl font-bold` | 24px | 700 | 1.2 | Page headings, card titles (WelcomeCard pattern) |
| Heading | `text-xl font-bold` | 20px | 700 | 1.2 | Modal titles, section headings, tab labels |
| Body | `text-sm font-normal` | 14px | 400 | 1.5 | Table cells, muted labels, notes textarea, descriptions |
| Label | `text-xs font-bold tracking-wide uppercase` | 12px | 700 | 1.4 | Table header row, badge labels, filter chip selected state uses `font-bold text-sm` |

**Weight rule:** Regular = 400 (`font-normal`), Bold = 700 (`font-bold`). Only two weights are used across the entire phase. Table headers and selected filter chips use `font-bold` (700) — they are already visually distinguished by `text-xs uppercase tracking-wide`, so the extra weight still provides clear hierarchy without a third weight.

**Font stack:** system-ui (no custom web font). Light sport theme uses default system sans-serif.

## Color

### 60 / 30 / 10 Split

| Role | Value | % | Usage |
|------|-------|---|-------|
| Dominant | `#F7F6F3` (`bg-background`) | 60% | Page background, table header row, hover row state (`hover:bg-background/60`) |
| Secondary | `#FFFFFF` (`bg-white`) | 30% | Cards (executive summary, WelcomeCard), sidebar, modal overlay container, table body |
| Accent | `#FF5C1A` (`primary`) | 10% | See reserved list below |

**Accent (#FF5C1A) reserved for:**
1. Selected filter chip border + background tint (`border-primary bg-primary/10 text-primary`)
2. Client tag chips (`bg-primary/10 text-primary border-primary/20`) — SpecialtyTagInput clone pattern
3. Active tab underline / indicator on client detail tab strip
4. Active sidebar nav item (`bg-primary/5 border-l-4 border-primary text-primary font-bold`)
5. Focus ring on inputs (`focus:ring-2 focus:ring-primary`)
6. "Vue lecture seule" badge background tint (`bg-primary/10 text-primary`)

**Destructive color:** `#DC2626` (`bg-red-600`) — reserved exclusively for:
- "Retirer" confirmation button in RevokeConfirmModal (`bg-red-600 hover:bg-red-700 text-white`)
- Revoke action link in roster table actions column (`text-red-600 hover:underline`)
- "Mood declining" signal chip (`bg-red-50 text-red-600 border-red-200`)

### Semantic Signal Colors

Signal chips on the roster table follow the KycStatusChip color-class pattern:

| Signal | Background | Text | Border | Condition |
|--------|-----------|------|--------|-----------|
| Missed sessions | `bg-red-50` | `text-red-600` | `border-red-200` | No workout_sessions in last 14 days |
| Stale measurements | `bg-yellow-50` | `text-yellow-700` | `border-yellow-200` | No body_measurements in last 28 days |
| Mood declining | `bg-red-50` | `text-red-600` | `border-red-200` | last-3 mood avg < prev-3 mood avg |
| Normal | `bg-green-50` | `text-green-700` | `border-green-200` | No signals triggered |

### Mood Trend Badge Colors (Executive Summary Card, D-10)

| Delta | Badge classes | Label example |
|-------|---------------|---------------|
| delta < -0.3 | `bg-red-50 text-red-600 border-red-200` | `Humeur: ↓ 3.2 → 2.8` |
| delta -0.3 to 0 | `bg-yellow-50 text-yellow-700 border-yellow-200` | `Humeur: ↓ 3.0 → 2.8` |
| delta > 0 | `bg-green-50 text-green-700 border-green-200` | `Humeur: ↑ 2.8 → 3.2` |
| insufficient data | `bg-neutral-100 text-neutral-500 border-neutral-200` | `Humeur: –` |

### `/coach/clients` — Roster Page

```
CoachSidebar (w-60, sticky) | main (flex-1)
  main:
    ─ Page heading: "Clients" (text-2xl font-bold text-text) + client count badge
    ─ Search input (text-sm, border-border, rounded-xl, px-4 py-2, w-64)
    ─ FilterChipGroup: ["Tous", "Séances manquées", "Mesures non mises à jour", "Humeur en baisse"]

```

**Primary focal point:** ClientsTable — full-width, high information density, dominant element of the roster page.

**Table columns (ordered):**
1. Checkbox (w-10, `aria-label="Sélectionner"`)
2. Client (avatar 32px circle + display_name + email) — min-w-[200px]

4. Signaux (up to 3 signal chips in flex row, gap-1) — min-w-[160px]
5. Compliance (sessions X/3 + habits Y%) — w-32
6. Actions (Voir, Retirer link) — w-28

**Empty state:** `py-16` centered, heading "Aucun client lié", body "Invitez votre premier client pour voir ses données ici.", CTA button `→ Gérer les invitations` linking to `/coach/invitations`.

## Interaction Contracts

### Multi-select Checkboxes (D-18)

- Each roster row has a checkbox in column 1.
- "Select all" checkbox in `<thead>` first column: indeterminate state when partial selection.
- Max 5 clients: when 5 are checked, remaining checkboxes become `disabled` + `cursor-not-allowed` + `opacity-40`.
- `CompareButton` label updates as `"Comparer (N)"` where N = selection count.
- `CompareButton` navigates to `/coach/clients/compare?ids=id1,id2,...`.

### Tag Input (ClientTagInput)

- Add on `Enter` or `,` key. Remove on chip `×` click. Backspace removes last tag when input empty.
- Max 20 tags. Placeholder: `"Ex : Hyrox, récup…"` (only shown when 0 tags).
- Tags are autosaved on blur (POST to backend) and on chip removal (DELETE to backend).
- No explicit "Save tags" button — immediate persistence.

### Private Notes (ClientNotesPanel)

- `<textarea>` full-width, `min-h-[120px]`, `border-border rounded-xl px-4 py-3 text-sm`.
- "Enregistrer les notes" button appears only when content has changed (dirty state).
- Button: `bg-primary text-white rounded-xl px-6 py-3 text-sm font-bold hover:bg-primary/90`.
- On save success: button disappears, `updated_at` timestamp shown below textarea in `text-xs text-muted`.

### Revoke Client Link (D-21)

- Trigger: "Retirer" link in roster table actions column, OR ghost button in ClientDetailHeader.
- Opens `RevokeConfirmModal` (reuse as-is) with these props:
  - `title`: `"Retirer ce client ?"`
  - `body`: `"[Prénom Nom] perdra l'accès à vos programmes assignés. Vous perdrez l'accès à leurs données."`
  - `confirmLabel`: `"Tapez COACH pour confirmer"`
  - `confirmCta`: `"Retirer"`
  - `cancelLabel`: `"Garder ce client"`
- On confirm: `DELETE /coach/clients/links/:clientId`, router.refresh(), toast "Client retiré."

### Tab Navigation (D-06)

- Tab links are `<Link href="/[locale]/(coach)/coach/clients/[id]/[tab]">`.
- Active tab detection via `usePathname().endsWith('/[tab]')`.
- Default route `/clients/[id]` → 302 redirect to `/clients/[id]/sessions`.
- Tab order (left to right): Séances · Mesures · Habitudes · Nutrition · Sommeil · Cardio · Journal.

### Load More (D-07)

- Each tab shows last 30 rows by default (server-fetched with `.limit(30)`).
- If count > 30: "Voir plus" button below table, `text-sm text-primary font-normal hover:underline`, triggers client-side fetch of next 30 and appends (simple state, no infinite scroll).
