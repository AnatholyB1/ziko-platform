    1. `useProfile()` — query key `['profile', userId]`, selects `name, goal, workout_frequency, fitness_level` from `user_profiles` WHERE `id = userId`, `.single()`, staleTime 10 min.

    2. `useStreak()` — query key `['streak', userId]`, queries `habit_logs` WHERE `user_id = userId` AND `completed = true` AND `date >= 60 days ago`, orders by date DESC, deduplicates by date using a Set, counts consecutive days backwards from today (decrement date by 86400000ms while Set contains that ISO date string). Returns the count integer.

    3. `useSleepToday()` — query key `['sleep', 'today', userId]`, selects `duration_hours, quality, bedtime, wake_time` from `sleep_logs` WHERE `user_id = userId` AND `date = today ISO string`, `.maybeSingle()` (not .single() — row may not exist). staleTime 10 min.

    4. `useHydrationToday()` — query key `['hydration', 'today', userId]`, selects `amount_ml, date` from `hydration_logs` WHERE `user_id = userId` AND `date = today ISO string`. Reduces array to `totalMl`. Returns `{ totalMl: number }`. staleTime 2 min.

    5. `useNutritionToday()` — query key `['nutrition', 'today', userId]`, selects `calories, protein_g, carbs_g, fat_g` from `nutrition_logs` WHERE `user_id = userId` AND `date = today ISO string`. Reduces to `totalCalories`. Returns `{ totalCalories: number, logs: array }`. staleTime 5 min.

    6. `useWeeklySessions()` — query key `['workouts', 'weekly', userId]`, selects `id, started_at, name, total_volume_kg` from `workout_sessions` WHERE `user_id = userId` AND `started_at >= 7 days ago ISO string`, ordered by `started_at` DESC. Returns array. staleTime 5 min.

    7. `useActiveAIProgram()` — query key `['program', 'active', userId]`, selects `*` from `ai_generated_programs` WHERE `user_id = userId` AND `is_active = true` (boolean, not string). `.maybeSingle()`. Returns row or null. staleTime 10 min.

    8. `useRecentSessions()` — query key `['workouts', 'recent', userId]`, selects `id, name, started_at, total_volume_kg, duration_seconds` from `workout_sessions` WHERE `user_id = userId`, ordered by `started_at` DESC, `.limit(3)`. Returns array. staleTime 5 min.
