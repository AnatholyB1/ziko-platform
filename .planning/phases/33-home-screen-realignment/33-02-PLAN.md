    1. Computes `sleepPct = data.sleepDurationH / 8` (target 8h)
    2. If `sleepPct >= 0.7`: push tip key `'sleep_good'`, tag `'Pré-séance'`, text `"Tu as bien dormi (${h}h${m > 0 ? m : ''}). Bon créneau pour pousser — vise +2.5 kg sur ta dernière série."` (where h = Math.floor, m = Math.round remainder×60)

    4. If `data.unmetHabitName && new Date().getHours() >= 12`: push tip key `'habit'`, tag `'Habitude'`, text `"Tu n'as pas encore loggué ${data.unmetHabitName} aujourd'hui. 2 minutes suffisent."`
    5. Always push default tip key `'default'`, tag `'Coach Ziko'`, text `"Consistance > intensité. Montre-toi aujourd'hui, même 30 minutes, ça compte."`
    Returns the array (may have 1–4 tips depending on user data).

    Export two async helpers for appStorage — BOTH using a 24h window (per HOME-03: both "Plus tard" and "J'applique" dismiss for 24h):
    - `async function isDismissed(tipKey: string, hoursWindow: number): Promise<boolean>` — reads `appStorage.getNumber(`coach_tip_dismissed_${tipKey}`)`, returns false if undefined, else `Date.now() - ts < hoursWindow * 3600 * 1000`
    - `export async function dismissTip(tipKey: string): Promise<void>` — calls `appStorage.set(`coach_tip_dismissed_${tipKey}`, Date.now())`

    The `isDismissed` helper accepts a `hoursWindow` parameter for flexibility, but the component calling it for both "Plus tard" and "J'applique" must pass `24` as the window (see plan 33-04 Task 1 for invocation).

    Export `function useAITips(data: HomeDataForTips): { tips: Tip[] }` using `useMemo` keyed on `data.sleepDurationH, data.hydrationMl, data.hydrationGoalMl, data.unmetHabitName`. Returns `{ tips: computeTips(data) }`.

    No async inside the hook itself — dismiss helpers are called imperatively from the component. No useEffect, no useState.
    Imports: `useMemo` from 'react', `appStorage` from `../lib/storage`.
