Créer le nouvel écran d'édition de profil. Imports requis : React, useState, useEffect, View, Text, ScrollView, TouchableOpacity, Image, TextInput, ActivityIndicator depuis react-native ; SafeAreaView depuis react-native-safe-area-context ; router depuis expo-router ; Ionicons depuis @expo/vector-icons ; useQueryClient depuis @tanstack/react-query ; useThemeStore, showAlert depuis @ziko/plugin-sdk ; useAuthStore depuis stores/authStore ; supabase depuis lib/supabase ; ImagePicker depuis expo-image-picker.

Structure de l'écran :
- Header : STHeader-like (chevron-back + titre "Modifier le profil") — reproduire le pattern de settings.tsx lignes 15-35, ne pas importer STHeader depuis @ziko/ui car ce composant est local à settings.tsx.
- Section avatar : View centré contenant soit Image (si avatarUrl) soit View initiales colorées (84×84, borderRadius:24, bg:avatarColor||'#FF5C1A'). En dessous un TouchableOpacity "Modifier la photo" (text primaire 12px/700) qui appelle handleAvatarPress.
- Formulaire : 4 champs dans un card (bg:surface, borderRadius:12, shadow md, paddingVertical:4) :
  - Nom (TextInput, placeholder "Ton prénom")
  - Bio (TextInput multiline, placeholder "Une courte description...", numberOfLines:3)
  - Objectif : picker maison — TouchableOpacity qui ouvre un mini-modal ou ActionSheet avec les 6 options GOAL_OPTIONS
- Bouton Enregistrer en bas (bg:#FF5C1A, text:#fff, borderRadius:12, padding:16)

Logique :
1. Au mount : lire profile depuis useAuthStore. Pré-remplir name, bio (depuis settings JSONB ?.bio ou column si existante), goal depuis profile.goal. Lire avatar_url depuis profile.avatar_url. Lire initiales depuis name.
2. handleAvatarPress → showAlert avec 3 boutons ["Prendre une photo" → launchCameraAsync, "Choisir dans la galerie" → launchImageLibraryAsync, "Annuler"]. Note : showAlert de @ziko/plugin-sdk accepte buttons identiques à Alert.alert.
3. Après sélection : result.canceled → return ; sinon appeler uploadAvatar(result.assets[0].uri).
4. uploadAvatar(uri) : fetch(uri) → blob → supabase.storage.from('avatars').upload(`${userId}/avatar.jpg`, blob, { contentType: 'image/jpeg', upsert: true }) → getPublicUrl → setAvatarUrl(publicUrl) → upsert user_profiles avec avatar_url → invalidateQueries(['profile', userId]).
5. handleSave : upsert user_profiles { id:userId, name, goal } → invalidateQueries(['profile', userId]) → router.back(). La bio n'a pas de colonne dédiée dans user_profiles — la stocker dans settings JSONB sous la clé 'bio' : charger settings existants, spread, upsert.
6. Afficher ActivityIndicator dans le bouton pendant saving/uploading.
7. Gestion d'erreurs : tout catch → showAlert('Erreur', message).

Card row pour chaque champ TextInput : paddingVertical:12, paddingHorizontal:12, borderBottomWidth:1, borderBottomColor:theme.border. Label 12px/700/muted uppercase au dessus du TextInput. TextInput : fontSize:14, color:theme.text, paddingTop:4.

Objectif selector : rendre un STRow-like avec la valeur actuelle en right + chevron. Au tap, afficher un bottom-sheet simplifié : View absolue en bas de l'écran avec les 6 options comme STRow pressables (ou ActionSheet via showAlert multi-boutons).
