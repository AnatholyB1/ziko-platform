## Spacing Scale

Declared values (must be multiples of 4 — standard set only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, message avatar gap |
| sm | 8px | Compact element spacing, chip inner padding, message bubble inner padding (top/bottom), alert dismiss button gap |
| md | 16px | Card horizontal padding, sidebar gap, input bar padding, message bubble horizontal padding |
| lg | 24px | Section padding, chat container top padding |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Chat empty state center offset, page top padding |
| 3xl | 64px | Full-page vertical center for empty state illustration zone |

Exceptions:
- Chat input bar height: 56px (comfortable textarea + send button)
- Tool-result card: 8px inner padding all sides (was 12px — remapped to 8px)
- Message bubble max-width: 640px (coach messages right-aligned, AI messages left-aligned)
- Alert panel: 16px inner padding, 8px gap between alert cards
- Chat messages area: `padding-bottom: 88px` (leaves room above fixed input bar)

### Screen 3: "Adapter avec l'IA" Button (on template pages)

This button appears on `/coach/programs/[id]/edit` or template view pages, near the assign action area.

#### Button Spec
```
┌───────────────────────────────────────────┐
│  <IoSparklesOutline size={16} />           │
│  Adapter avec l'IA                         │
└───────────────────────────────────────────┘
```
- Variant: secondary (outlined), not primary — it is a supplementary action alongside "Assigner"
- Dimensions: `h-10 px-4 py-2`
- Default: `flex items-center gap-2 border border-primary text-primary bg-transparent rounded-lg text-sm font-semibold hover:bg-primary/5 transition-colors` (font-medium → font-semibold)
- Hover: `bg-[#FF5C1A]/5` (5% orange tint on background — this is where accent fill first appears)
- Active/loading: `bg-[#FF5C1A]/10` (10% orange tint) + icon replaced with `<IoRefreshOutline size={16} className="animate-spin" />` + text becomes "Ouverture..."
- Disabled: `opacity-40 cursor-not-allowed` (when no clients are linked)
- Placement: in the template action row, after "Dupliquer" button and before "Assigner"
- On click: navigates to `/{locale}/coach/ai?template={programId}&client={targetClientId}`
- If no client pre-selected: navigates to `/coach/ai?template={programId}` — the AI chat page shows a pre-filled prompt asking the coach to specify a client

#### Button Placement on Programs Page
The "Adapter avec l'IA" button is added to `ProgramCard.tsx` context menu or action row:
```
[Modifier]  [Dupliquer]  [✦ Adapter avec l'IA]  [Assigner]  [···]
```
It is rendered conditionally only for templates (`is_template=TRUE`).
