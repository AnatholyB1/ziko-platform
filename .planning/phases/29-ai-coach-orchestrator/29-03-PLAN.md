| Boundary | Description |
|----------|-------------|
| browser → /coach/ai/chat/stream | accessToken passed as Bearer header; never stored in URL or localStorage |
| Server Component → Supabase | createServerSupabase() uses cookie-based auth; access_token extracted server-side only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-10 | Information Disclosure | accessToken prop in AIChatClient | mitigate | Token passed as prop (server→client) but never rendered to DOM or stored; used only as Authorization header in fetch calls |
| T-29-11 | Tampering | Deep-link prefill auto-send | mitigate | template/client params come from URL query string (coach-controlled); pre-filled message is coach's own input — no cross-user data injected |
| T-29-12 | Elevation of Privilege | SSE stream reads | accept | Stream is gated by authMiddleware on backend; client-side cannot forge the conversationId to access another user's messages |
| T-29-SC | Tampering | npm/pip/cargo installs | mitigate | No new package installs in this plan; gsap already installed |
</threat_model>
