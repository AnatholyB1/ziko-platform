## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-07-01 | Tampering | ProgramEditorClient PUT | mitigate | weeks_data validated by Zod ProgramWeekSchema[] on backend before DB write (plan 27-04) |
| T-27-07-02 | Elevation of Privilege | AssignmentModal client list | mitigate | Client list fetched from GET /coach/clients which only returns coach's linked clients; POST /assign backend validates is_coach_of() per client_id |
| T-27-07-03 | Tampering | Shared note write | mitigate | 500-char limit enforced at route level (plan 27-05); textarea maxLength=500 attribute on client for UX |
| T-27-07-04 | Tampering | Delete program from editor | mitigate | Delete requires RevokeConfirmModal typed confirmation ("SUPPRIMER") + ?confirmed=true query param on backend |
