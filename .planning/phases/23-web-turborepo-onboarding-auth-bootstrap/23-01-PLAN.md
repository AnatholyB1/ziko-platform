## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer workstation → git remote (origin) | force-push of branch after `git reset --hard` is a write to shared history |
| node_modules hoisting from root → apps/web bundler | dependency resolution crosses package boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-01-01 | I (Information Disclosure) | web bundle including react-native-worklets | mitigate | Remove root `react-native-worklets` so it cannot hoist into `node_modules` reachable from `apps/web`. Wave 6 bundle-analyzer job is the defense-in-depth verification. |
| T-23-01-02 | T (Tampering) | force-push of rollback to remote branch | accept | Force-push is gated on D-02 explicit failure. The `pre-web-onboarding` tag itself is immutable on origin (tags are not force-pushable without `--force` flag, which the rollback doc does not use). |

</threat_model>
