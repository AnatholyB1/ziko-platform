### Issues Fixed

1. **404 flood — `@supabase/ssr` source maps in dev**
   - Root cause: `next dev --turbopack` bypasses the webpack config entirely; Turbopack serves SSR source maps, browser requests referenced `.ts` files → flood of 404s
   - Fix: removed `--turbopack` from `apps/web/package.json` `dev` script; removed dead `webpack:` block from `next.config.ts`

2. **`_next/image` 400 on profile photo**
   - Root cause: `/api/photo` route didn't exist; `_next/image` internal fetch doesn't forward session cookies → auth fails → 400
   - Fix: created `apps/web/src/app/api/photo/route.ts` (authenticated proxy to `coach-kyc` Supabase bucket); added `unoptimized` to `<Image>` in `PhotoUpload.tsx` so browser fetches directly with cookies

3. **Upload `ERR_CONNECTION_REFUSED` to `localhost:8080`**
   - Root cause: `PhotoUpload` and `FileUploadRow` called `${apiUrl}/storage/upload-url` (Hono backend) which wasn't running
   - Fix: created `apps/web/src/app/api/storage/upload-url/route.ts` — mirrors Hono logic (bucket allowlist + path ownership + `createSignedUploadUrl`) using `createServerSupabase()`

4. **Web app fully decoupled from Hono backend**
   - `coach-identity.ts` Server Actions (`promoteRole`, `saveProfile`, `saveKyc`) rewritten to call Supabase directly instead of Hono `/coach/identity/*`
   - `FileUploadRow.tsx` and `PhotoUpload.tsx` both point to `/api/storage/upload-url`
   - Hono backend no longer needed for local web development

5. **Backend dev port set to 8080**
   - `PORT=8080` added to `backend/api/package.json` `dev` script to avoid collision with Next.js on port 3000
