# Requirements Archive — v1.8 Sport Dashboards

**Workstream:** main (web/coach — Next.js)
**Milestone:** v1.8 Sport Dashboards
**Archived:** 2026-05-30

---

## Dashboard Tab

- [x] **DASH-01**: Coach can open a "Dashboard" tab in the client detail view
- [x] **DASH-02**: Coach can select a sport type from a dropdown to load the matching dashboard instantly (no configuration required)
- [x] **DASH-03**: Coach can filter chart data by date range (week / month / 3 months)
- [x] **DASH-04**: Coach can compare two clients or two periods side-by-side on the same dashboard
- [x] **DASH-05**: Coach can export the client's active dashboard as a PDF

## Powerlifting Dashboard

- [x] **PL-01**: Coach sees 1RM SBD progression chart — estimated 1RM for Squat, Bench, and Deadlift over time
- [x] **PL-02**: Coach sees Fatigue via RPE trend — session average RPE over time (early burnout warning signal)
- [x] **PL-03**: Coach sees Weekly Tonnage chart — total kg lifted per week
- [x] **PL-04**: Coach sees Intensity % chart — percentage of 1RM per session over time

## Hyrox Dashboard

- [x] **HYR-01**: Coach sees Hyrox dashboard — station splits, finish times, weekly training volume

## Running / Cardio Dashboard

- [x] **RUN-01**: Coach sees Running dashboard — pace trend, distance, VO2max estimate, weekly km

## Bodybuilding / Hypertrophy Dashboard

- [x] **BB-01**: Coach sees Bodybuilding dashboard — volume per muscle group, progressive overload tracking, bodyweight trend

## Weight Loss / Injury Return Dashboard

- [x] **WL-01**: Coach sees Weight Loss / Injury Return dashboard — bodyweight curve, calorie compliance, load progression for rehabilitation

## AI Context Injection

- [x] **AI-01**: Active sport + key dashboard metrics are injected into the coach chat system prompt, enabling contextual AI analysis for that client
- [x] **AI-02**: Dashboard displays AI-generated insight chips on each chart (e.g. "Fatigue trending up this week")
- [x] **AI-03**: Dashboard shows a one-paragraph AI narrative summary card of the client's overall performance
- [x] **AI-04**: Coach can set numeric alert thresholds per metric; AI flags the coach when a client crosses a threshold

## Future Requirements (deferred to v1.9+)

- Coach-configurable custom chart layouts (drag-and-drop)

## Out of Scope (maintained for v1.8)

- Dark mode — light sport theme only
- New data collection — dashboards read existing tables only; no new workout logging features
- Mobile-native coach dashboard — web only in v1.8
- CSV/Excel export — PDF export only in v1.8
