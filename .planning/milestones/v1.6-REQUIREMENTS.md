- [x] **COACH-01**: `plugins/coach/` directory exists with complete `manifest.ts` (default export, `id: 'coach'`, `mandatory: true`, `showInTabBar: false`, Ionicons icon, fr+en metadata, `routes`, `aiTools`, `aiSkills`).
- [x] **COACH-02**: Coach plugin registered in `apps/mobile/src/lib/PluginLoader.tsx` static `PLUGIN_LOADERS` map.
- [x] **COACH-03**: Plugin automatically installed (`user_plugins` record with `is_enabled: true`) for any user with `role = 'client' | 'both'` on first sign-in.
- [x] **COACH-04**: "Désinstaller" button in plugin store is grayed out and non-interactive for the coach plugin; tooltip explains it is mandatory. *(GAP-01 fixed: migration 047 adds coach to `plugins_registry` with `"mandatory":true`.)*

### Screen UX — 3 States

- [x] **COACH-06**: State A — 6-character `<TextInput>` with auto-uppercase, charset filter `[A-Z2-9]`, paste support, submit CTA enabled only when 6 valid characters present.
- [x] **COACH-07**: State B — coach preview card (photo, display_name, specialties chips, bio, KYC badge) with "Lier mon compte" CTA; data from `GET /coach/clients/links/preview?code=XXXXXX`.
- [x] **COACH-08**: State C — coach card with "Lié depuis [date]" and "Retirer ce coach" action. *(GAP-02 tech debt: blank screen when coach profile row missing — no fallback branch.)*
- [x] **COACH-09**: Error messages in State A use constant-time copy — same message regardless of whether code exists or not.
- [x] **COACH-10**: Figma design contract produced before screen implementation; UI-SPEC.md covers all 3 states with light sport theme values.

### Revocation from Settings

- [x] **COACH-11**: `settings.tsx` includes "Mon coach" section visible only when `role = 'client' | 'both'` and coach is linked.
- [x] **COACH-12**: "Retirer ce coach" opens typed-confirmation modal requiring user to type "COACH" before confirm becomes active.
- [x] **COACH-13**: On confirmation, app calls `DELETE /coach/clients/links/:id`, clears local state, returns to State A.

### i18n

- [x] **COACH-14**: All user-facing strings use `useTranslation()` with `coach.*` namespace; both `fr` and `en` translation files complete (22 keys).

### AI Tools

- [x] **COACH-15**: Manifest declares `aiTools: [coach_get_link, coach_revoke_link]` with JSON Schema; tools registered in backend AI tool registry (`backend/api/src/tools/registry.ts`).
