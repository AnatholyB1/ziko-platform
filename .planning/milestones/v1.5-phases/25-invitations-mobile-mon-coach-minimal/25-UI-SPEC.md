## Spacing Scale

Declared values (multiples of 4 only). Matches existing coach dashboard patterns.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inner padding |
| sm | 8px | Compact element spacing (e.g. chip groups, gap between status chip + code) |
| md | 16px | Default element/card internal padding |
| lg | 24px | Card padding (matches existing `p-6 = 24px`) |
| xl | 32px | Section gaps within a page |
| 2xl | 48px | Major section breaks (e.g. page header to content) |
| 3xl | 64px | Page-level vertical spacing |

Exceptions:
- Generated-code display card: `py-8 px-10` (32px/40px) to give the large mono code breathing room
- Typed-confirmation modal inner padding: `p-8` (32px) to make destructive context legible

## Typography

Based on existing coach component patterns (`WelcomeCard.tsx`, `KycStatusChip.tsx`, `CoachSidebar.tsx`). The web app uses Tailwind utility classes directly — no custom font scale beyond Tailwind v4 defaults.

| Role | Size | Weight | Line Height | Tailwind Class |
|------|------|--------|-------------|----------------|
| Body | 14px | 400 (normal) | 1.5 | `text-sm font-normal` |
| Label / Caption | 12px | 600 (semibold) | 1.4 | `text-xs font-semibold` |
| Heading | 20px | 700 (bold) | 1.2 | `text-xl font-bold` |
| Display / Code | 36px | 700 (bold) | 1.0 | `text-4xl font-bold tabular-nums` |

**Only two weights are used: 400 (normal) and 700 (bold).** Semibold (600) is reserved exclusively for status chip labels to match `KycStatusChip` precedent (`font-bold` in that component maps to Tailwind default bold at 700 — chips use `font-bold` too, so weight stays at 700).

**Monospaced code display:** The generated invitation code (e.g. `ZK4F2A`) uses `font-mono tabular-nums` at `text-4xl font-bold`. This is the only monospaced context in this phase.

## Accessibility Constraints

- Code input: `aria-label="Code d'invitation"`, `aria-describedby` pointing to inline error when visible
- Copy buttons: `aria-label="Copier le code d'invitation"` / `aria-label="Copier le lien de partage"` (not just "Copier" — screen readers need full context)
- Modal: `role="dialog"`, `aria-modal="true"`, `aria-labelledby` on title, focus trap inside, `Escape` key closes
- Destructive button: `aria-disabled="true"` + `disabled` when confirm input does not match
- Status chips: `<span>` not `<button>` — they are read-only indicators
- Coach photo: `alt="{display_name}, coach Ziko"` or `alt=""` if decorative-only fallback avatar
