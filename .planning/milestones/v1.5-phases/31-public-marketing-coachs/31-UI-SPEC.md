| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding vertical |
| sm | 8px | Chip padding, inline gap between badge items |
| md | 16px | Default element spacing, card inner padding |

| xl | 32px | Section inner padding top/bottom (mobile) |

## Typography

Matches MOODBOARD.md + existing marketing site conventions.

**Design system scale: 4 sizes, 2 weights.**

> Implementation note: Tailwind utility classes such as `font-black`, `font-semibold`, and responsive size variants (`text-5xl md:text-7xl`) are implementation details, not additional scale steps. The `font-black` hero treatment and `font-semibold` micro-usages in components are Tailwind shortcuts that resolve to the two declared weights below — they do not expand the scale.

| Role | Size | Weight | Line Height | Tailwind Class | Usage |
|------|------|--------|-------------|----------------|-------|
| Display / Heading | 36px desktop (responsive: `text-3xl md:text-4xl`) | 700 Bold | 1.15 | `text-3xl md:text-4xl font-bold` | All section headings (Video, Features, Comparison, Founder, FAQ, Final CTA). Hero headline is a responsive variant of this token: `text-5xl md:text-7xl font-bold leading-none tracking-tight` — treated as a responsive Tailwind variant, not a distinct scale step. |
| Feature / Item Title | 22px | 700 Bold | 1.2 | `text-xl font-bold` | Feature block titles, FAQ section heading, comparison column headers |
| Body | 16px | 400 Regular | 1.6 | `text-base text-muted leading-relaxed` | Hero subtitle, section lead text, FAQ answers, feature descriptions, founder story, footer subheading |
| Label / Badge | 12px | 700 Bold | 1.4 | `text-xs font-bold` | Pill badges, table labels, caption text, comparison table cell values, beta note |

**Tracking:** `tracking-tight` on Display/Heading role only. All other text: default tracking.
**No italic** — never used. **No underline** except genuine hyperlinks.
