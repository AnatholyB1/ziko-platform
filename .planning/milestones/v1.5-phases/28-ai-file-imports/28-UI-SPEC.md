## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, chip inner horizontal |
| sm | 8px | Compact element spacing, table cell vertical padding |
| sm+ | 12px | Inner component gaps, badge/chip outer padding, diff banner padding |
| md | 16px | Default element spacing, card horizontal padding |
| md+ | 20px | Mobile card inner padding, upload progress card sides |
| lg | 24px | Section padding, accordion inner padding |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Major section breaks, page top padding, parsing card inner padding |
| 3xl | 64px | Page-level spacing on web |

Exceptions:
- Exercise table row min-height: 44px (touch-target compliance)
- Upload drop zone: 160px tall on web, full-width on mobile
- Mobile screen horizontal padding: 16px (md)
- Mobile paddingBottom: 100px (tab bar clearance — mandatory per CLAUDE.md)
- Status chip inner padding: 4px vertical × 8px horizontal

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Display | 28px | 600 | 1.2 | Web page titles (Imports, Import Detail) |
| Heading | 18px | 600 | 1.35 | Section headings, card/modal titles, accordion week titles, mobile screen headings |

## Implementation Notes for Executor

### Critical Design Rules
1. **Yellow confidence highlight:** `#FEF9C3` background on exercise table cells where `confidence < 0.70`. Clear the highlight when the user edits the cell value (field is now user-confirmed).
2. **Parsing progress bar:** Never show indeterminate shimmer. Use a timed fill (0→90% over 55s) that visually communicates expected duration, then pulse at 90% while waiting. This is more honest than infinite loaders.
3. **Status chip — parsing:** Must animate (opacity pulse). A static chip for a live async state violates the "alive" principle from the mood board.
4. **Diff view — unchanged rows:** Dimmed to 60% opacity with a "tout afficher" toggle when more than 3 unchanged rows exist. Focus attention on what changed.
5. **Mobile paddingBottom: 100** — mandatory on all ScrollViews per CLAUDE.md (tab bar clearance).
6. **No `Alert.alert`** on mobile — use `showAlert` from `@ziko/plugin-sdk` for all destructive confirmations.
7. **Accordion default state:** All weeks collapsed on initial render. User expands to inspect. This prevents overwhelming coaches with 12-week program data.
8. **Credit cost visibility:** The credit cost card MUST be visible before the user initiates upload. It is placed immediately below the upload zone / pick file button, not buried in a tooltip.

### Platform-Specific Constraints
- **Web:** `export const dynamic = 'force-dynamic'` and `export const revalidate = 0` on all `(coach)` pages per Phase 23 D-15.
- **Web:** Icons from `react-icons/io5` (not Ionicons — web build)
- **Mobile:** Icons from `@expo/vector-icons` Ionicons (not react-icons — RN build)
- **Mobile:** NativeWind v4 classes or inline style objects only — no StyleSheet
- **Mobile:** `showAlert` from `@ziko/plugin-sdk` for all alerts
