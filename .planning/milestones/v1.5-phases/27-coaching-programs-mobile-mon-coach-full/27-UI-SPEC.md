## Spacing Scale

### Web (Tailwind classes — Track A)

| Token | Tailwind | px | Usage |
|-------|----------|----|-------|
| xs | `gap-1` / `p-1` | 4px | Icon-label gaps, chip internal padding |
| sm | `gap-2` / `p-2` | 8px | Chip groups, compact row gaps |
| md | `gap-4` / `p-4` | 16px | Card inner padding, form field gaps |
| lg | `gap-6` / `p-6` | 24px | Section vertical rhythm, card outer margin |
| xl | `gap-8` / `p-8` | 32px | Page section breaks |
| 2xl | `gap-12` / `p-12` | 48px | Major layout separators |
| 3xl | `gap-16` / `p-16` | 64px | Page-level top padding |

Exceptions:
- Week accordion row height: `h-12` (48px) — matches existing `ClientTabStrip` row targets
- Slide-over panel width: `w-[480px]` — fixed, not on scale (required for exercise table legibility)
- Modal max-width: `max-w-md` (448px) — matches `RevokeConfirmModal` pattern
- Exercise table row height: `h-11` (44px) — minimum accessible touch/click target
- Sidebar width: `w-60` (240px) — matches existing `CoachSidebar`

### Mobile (React Native points — Track B)

Inherits Phase 28 UI-SPEC spacing scale exactly:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4 | Icon gaps, chip padding |
| sm | 8 | Between elements within a block |
| md | 16 | Block inner padding, section gap |
| lg | 24 | Between new content blocks |
| xl | 32 | Between major sections |
| tab-clearance | 100 | paddingBottom on ScrollView |

Exceptions (inheriting Phase 28 approved exceptions plus Phase 27 additions):

- Exactly 2 weights in use: 400 (normal) and 700 (bold).

- Page titles match existing `dashboard/page.tsx` heading style (`text-2xl font-bold`).
