### Spacing Exceptions (Mockup-Override)

The following values deviate from the standard grid set {4, 8, 12, 16, 20, 24, 32, 48, 64}. Each is a bounded exception required to match the canonical `home.jsx` mockup exactly. The official scale above governs all other spacing decisions; these are overrides only where `home.jsx` mandates a precise non-grid value.

| Value | Usage | home.jsx Reference | Nearest Grid | Override Reason |
|-------|-------|---------------------|--------------|-----------------|
| 14px | Card inner padding (sm cards), `marginBottom` in header/MissionCard exercise lists, PluginsDrawer gap | line 131 (`padding: "var(--pad)"` ≈ 14px), line 265 (`marginTop: 14, marginBottom: 14`) | 16px | Mockup pixel-authority: sub-2px deviation visible in 375px viewport |
| 10px | `marginTop` in FormeDuJour body row, QuickLog cell vertical padding | line 139 (`marginTop: 10`), line 310 (`padding: "10px 8px"`) | 8px | Mockup pixel-authority |
| 18px | MissionCard inner padding | line 251 (`padding: 18`) | 16px | Mockup pixel-authority |

Additional non-exceptional spacing notes:
- QuickLog grid gap: 8px (grid token `sm`)

## Motion Design

> Personality: Snappy + Fluid (200ms power2.out for entrances, 100ms for press feedback)
> Platform: react-native-reanimated v3 — use `FadeInUp`, `withSpring`, `withTiming`

| Screen / Section | Animation | Duration | Easing | Reanimated Pattern |
|------------------|-----------|----------|--------|--------------------|
| HomeScreen entrance | Full screen fade + slide up | 250ms | power2.out | `FadeInUp.duration(250).springify()` on root ScrollView |
| FormeDuJour ring | Segments animate from 0 to value | 600ms | power2.out | `withTiming(targetDashOffset, {duration:600})` on each Circle's dashOffset |
| FormeDuJour score counter | Count-up from 0 to score | 800ms | ease-out | `useAnimatedProps` on Text with `Math.round(withTiming(score, {duration:800}))` |
| Segment rows | Stagger fade-in, each row delayed | 150ms + 50ms/row | power2.out | `FadeInUp.delay(i*50).duration(150)` |
| MissionCard entrance | Fade + slight scale from 0.97 | 200ms | power2.out | `FadeIn.duration(200)` with `withTiming(1, {duration:200})` on scale |
| AICoachInline tip swap | Previous fades out, next fades in | 300ms | power2.inOut | Animated opacity crossfade on `key={tipIndex}` |
| SmartActions scroll reveal | Cards fade in as they scroll into view | 200ms | power2.out | `FadeInRight.duration(200)` on each card |
| QuickLog press feedback | Scale down to 0.96 then bounce back | 100ms | power3.out | `withSpring(0.96)` → `withSpring(1)` on Animated.View scale |
| QuickLog active state | Border color transition | 150ms | linear | `withTiming(activeColor, {duration:150})` on borderColor |
| QuickLog confirmed badge | Fade-in from opacity 0 | 200ms | power2.out | `FadeIn.duration(200)` on confirmed span |
| WeekStrip cells | Stagger reveal, left to right | 80ms/cell, 40ms delay | power2.out | `FadeInUp.delay(i*40).duration(80)` |
| PluginsDrawer open | Bottom sheet slides up | 300ms | spring (damping 20) | `MotiView from={translateY:400} animate={translateY:0}` |
| PluginsDrawer plugin tap | Scale down 0.95, ripple | 100ms | power3.out | `withSpring(0.95)` → `withSpring(1)` |
| Recent rows | Stagger fade + slide | 150ms + 60ms/row | power2.out | `FadeInUp.delay(i*60).duration(150)` |

## Interaction Spec

### QuickLog — Water (+250ml)

1. User taps "+250ml" button
2. Immediate: scale feedback (0.96 → 1.0, 100ms)
3. Immediate: border turns blue (#3B82F6), label updates to current total (e.g. "1.75L")
4. Fire-and-forget: `POST /ai/tools/execute` with `{ tool: 'hydration_log', input: { amount_ml: 250 } }`
5. On success: confirmed indicator "+250ml" fades in
6. On error: silent (fire-and-forget — do not show error for quick logs)

### QuickLog — Mood

1. User taps "Humeur" button
2. Bottom sheet opens: 5-emoji picker (😫😕😐🙂😁) + optional context chips (pré-séance/matin/soir)
3. User selects emoji → confirms
4. Fire-and-forget: `POST /ai/tools/execute` with `{ tool: 'journal_log_mood', input: { mood: 1-5, context: 'morning' } }`
5. Button border turns green, "✓ logué" confirmed badge

### QuickLog — Weight

1. User taps "Poids" button
2. Bottom sheet with numeric input (pre-filled with last logged weight)
3. Confirm → fire-and-forget: `POST /ai/tools/execute` with `{ tool: 'measurements_log', input: { weight_kg: N } }`
4. Border turns amber, "✓ logué"

### QuickLog — Meal

1. User taps "Repas" → navigates to Nutrition plugin "Ajouter" tab
2. No sheet (direct navigation)
3. Border does NOT activate (navigation intent, not a log action)

### AICoachInline — "J'applique"

1. User taps "J'applique"
2. Immediate button feedback (scale 0.97 → 1.0)
3. Dismiss tip for 24h (stored in Zustand / MMKV)
4. Action logged via relevant endpoint based on tip type:
   - Pre-workout tip → no API call (motivational only)
   - Hydration tip → same as QuickLog water (+250ml)
   - Habit tip → navigate to Habits plugin
5. Next tip in rotation shown

### AICoachInline — "Plus tard"

1. User taps "Plus tard"
2. Current tip dismissed for 6h (MMKV timestamp)
3. Next tip shown immediately (no animation, instant swap)

### MissionCard — "Allez, c'est parti !"

1. Scale feedback (0.97 → 1.0, 100ms)
2. Navigate to `/(app)/workout` with session ID as parameter
3. Pre-start the session (or navigate to ProgramDetail which has "Démarrer séance" CTA)

### PluginsDrawer — Open

1. User taps "Tous mes outils" card
2. Overlay animates in (opacity 0 → 0.40, 200ms)
3. Sheet slides up from bottom (translateY 400 → 0, spring damping 20)
4. Plugin grid renders with stagger (each icon tile FadeInUp with 30ms delay)
