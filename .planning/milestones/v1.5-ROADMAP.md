# Milestone v1.5: Coach Platform & CRM

**Status:** ✅ SHIPPED 2026-05-22
**Phases:** 22–31 (+ Phase 36 Web Performance Optimization — appended during execution)
**Total Plans:** 61 (+ Phase 36: 2 plans = 63 delivered)

## Overview

Transforms Ziko from a single-tenant athlete app into a two-sided platform: a bounded-context coach web CRM on Next.js, self-serve coach identity + KYC onboarding, a 6-char invitation link system between coach and athlete, a full client roster with 7-tab read-only data views, coaching program authoring and fork-on-assign, AI file imports (PDF/image/Excel/Word → Zod-validated programs), an AI coach orchestrator with 3 tools + SSE chat UI + weekly digest, and a static public marketing page `/coachs` (FR/EN).

Architecture keystone: `is_coach_of(coach UUID, client UUID)` SECURITY DEFINER STABLE SQL function extends 11 athlete tables with a separate `FOR SELECT` policy — coach reads, never writes, GDPR-clean.

Phase 30 (Strava Integration) was explicitly skipped / deferred to v1.6.

## Milestone Summary

**Timeline:** 2026-05-13 → 2026-05-22 (10 days)
**Commits:** ~50 feat/docs/fix commits on main branch

**Key Decisions:**

- `is_coach_of()` SECURITY DEFINER STABLE — sole pattern for cross-user RLS reads; separate FOR SELECT policies preserve existing FOR ALL write policies (GDPR clean)
- `apps/web/` onboarded via git subtree (no --squash) — full ziko-web history preserved; D-01 triple-green PASS; dual-repo fallback 23-02b not triggered
- `@supabase/ssr` dual-store cookies — fresh tokens propagate to downstream Server Components; stale JWT loops prevented
- Marketing pages in `(marketing)` route group — prevents CoachSidebar leaking into public pages
- All redirects with `getLocale()` prefix — loginAction returned hardcoded locale-less paths causing 404 in next-intl
- NEXT_PUBLIC_API_URL set in apps/web — missing env var caused Silent "Failed to fetch" on storage upload
- `coach-sdk` peerDependency zod ^4.0.0 + external:['zod'] in tsup — prevents zod-instance drift; CJS bundle 3.6 KB
- Phase 27 Track B mobile deferred — 3 gaps delegated to Phase 41 in milestone-mobile workstream
- Signed-URL upload pattern for Phase 28 — bypasses Vercel 4.5 MB body limit (same pattern as v1.3)
- `@ziko/email` tsx source exports (no build step) — @types/react must NOT be in email package devDeps (React 18/19 type mismatch)
- `fetchCoachContext` two-query pattern — JWT for links, service client for names (RLS blocks cross-user profile reads)
- `safeNext` moved from 'use server' to lib/safe-next.ts — Next.js Server Action constraint
- React `cache()` for getCachedCoachUser — one getUser() DB call per request (Phase 36 optimization)

**Issues Resolved:**

- Phase 24 locale redirect bug — loginAction hardcoded paths → `getLocale()` prefix
- Phase 25 rate-limit constant-time envelope — prevents per-cause information leak
- Phase 25 RevokeConfirmModal focus trap — keyboard-trapping missing from modal
- Phase 26 ComparisonChart SSR crash — Recharts ResizeObserver → `use client` + fixed height
- Phase 29 coach AI context — RLS blocked cross-user profile reads → two-query pattern
- Phase 29 SSE buffering — Next.js proxy was buffering SSE chunks → direct pipe
- Phase 29 `add coach_chat to DAILY_QUOTAS` — getQuotaStatus crashed with TypeError

**Issues Deferred:**

- STRAVA-01–07 (Strava Integration) — out of scope for v1.5, deferred to v1.6
- Phase 27 Track B mobile (MOBILE-02/03/04/06) — 3/13 gaps deferred to Phase 41 (milestone-mobile)

- Coach billing, scheduling, admin back-office — v1.6+ ERP roadmap
