<objective>
Extend the existing Supabase webhook handler in `webhooks.ts` to support the TRIGGER-02 "after-N-sessions" trigger. When `workout_sessions` receives a new row (type === 'INSERT'), the handler:

1. Identifies the athlete (record.user_id) and their linked coach (via coach_client_links)
2. Counts the athlete's total sessions in the same program (record.program_id)
3. Calls `create_form_instances_for_trigger('after_n_sessions', athleteId, coachId, sessionCount)` so any form with `trigger_config = {"type":"after_n_sessions","n":N}` matching that count creates a pending instance

Purpose: workout_sessions is written directly by the mobile app to Supabase (no dedicated Hono endpoint). The Supabase webhook is the only server-side hook for this event.

Output: Modified `backend/api/src/routes/webhooks.ts` with the new branch under the existing POST /supabase handler.
</objective>
