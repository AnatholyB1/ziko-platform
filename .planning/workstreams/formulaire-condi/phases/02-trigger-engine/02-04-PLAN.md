<objective>
Implement the TRIGGER-03 "fixed-date" cron trigger: a daily Vercel cron job that scans for active forms with a `fixed_date` trigger whose date has been reached, then creates pending instances for all athletes linked to each matching coach.

This plan adds two things:
1. A new route `GET /forms/cron/trigger-fixed-date` in `forms.ts` — secured by `CRON_SECRET` env var (not authMiddleware), called by Vercel cron
2. A new cron entry in `backend/api/vercel.json` at `"0 6 * * *"` (daily 6am UTC)

Purpose: Fixed-date forms cannot be triggered reactively — they require a daily scan. The cron runs independently of any user action.

Output: Modified `forms.ts` (new cron route registered outside `router.use('*', authMiddleware)` block) + modified `vercel.json`.
</objective>

    Register the cron route on `cronRouter` (NOT on `router`):

    `cronRouter.get('/cron/trigger-fixed-date', async (c) => { ... })`

    Handler logic:
    1. Secret check: `const secret = c.req.header('X-Cron-Secret'); if (secret !== process.env.CRON_SECRET) return c.json({ error: 'Unauthorized' }, 401)`
    2. Build today's ISO date string: `const todayISO = new Date().toISOString().slice(0, 10)` (YYYY-MM-DD)
    3. Fetch all active fixed_date forms: `supabase.from('coach_forms').select('id, coach_id, trigger_config').eq('status', 'active').filter('trigger_config->>type', 'eq', 'fixed_date')`
       - Filter in JS: keep only forms where `(form.trigger_config as any).date <= todayISO`
    4. For each matching form:
       a. Fetch all active athletes for the coach: `supabase.from('coach_client_links').select('client_id').eq('coach_id', form.coach_id).is('revoked_at', null)`
       b. For each athlete, call `supabase.rpc('create_form_instances_for_trigger', { p_trigger_type: 'fixed_date', p_athlete_id: athlete.client_id, p_coach_id: form.coach_id, p_date: todayISO })`
    5. Accumulate total `created` count across all forms and athletes
    6. Return 200 `{ processed_forms: matchingForms.length, total_created: created }`

    Error handling: wrap in try/catch; log `[forms/cron/trigger-fixed-date]`; return 500 on failure.

    Update the export at the bottom of the file: export both routers:
    `export { router as formsRouter, cronRouter as formsCronRouter }`

    Then in `backend/api/src/app.ts`, add the import and mount:
    - Import: `import { formsRouter, formsCronRouter } from './routes/forms.js'`
    - Mount: `app.route('/forms', formsCronRouter)` — add immediately after the existing `app.route('/forms', formsRouter)` line

    Note: the module-scope `supabase` client in forms.ts (no JWT, publishable key only) is sufficient for the cron route — the create_form_instances_for_trigger function is SECURITY DEFINER.
