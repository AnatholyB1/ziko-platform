# UI-SPEC: Phase 03 — Coach Form Builder (Web)

> Visual and interaction contract for the Coach CRM Form Builder feature.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.
> **This document is the written contract. Figma frames are the visual source of truth.**

---

## Overview

A new top-level "Formulaires" CRM section where coaches create, edit, and publish conditional questionnaires. The form builder is a single scrollable page with three labelled sections: Questions, Déclencheur, and Publication. Questions are stacked editable cards with inline expansion. Trigger config lives below the question list on the same page. The publish action opens a modal targeting one client or all clients.

Design persona: Linear-precision data tool meets Notion block editor. No modals for editing — all edits are inline. Status badges are the primary visual language for form lifecycle.

## Interaction Contracts

### Question card expand/collapse
- Click anywhere on collapsed card → expand (inline editor appears, card border turns `border-primary border-2`)
- Only one card can be expanded at a time — clicking another card auto-collapses the current expanded card (saving pending edits with a confirm-or-discard prompt if label field is dirty)
- "Annuler" → collapses card, discards unsaved edits
- "Enregistrer" → validates (non-empty label + min 2 choices for Choix unique) → updates card display → collapses

### Question reorder
- ↑ button (`aria-label="Déplacer vers le haut"`): moves card one position up in array; disabled (`opacity-30`, non-interactive) on index 0
- ↓ button (`aria-label="Déplacer vers le bas"`): moves card one position down in array; disabled on last index
- No animation required on reorder — immediate DOM swap acceptable; GSAP stagger reindex is optional

### Add question
- "+ Ajouter une question" → appends new blank card at bottom of list → immediately expands the new card (type defaults to "Texte libre", label empty)
- Focus moves to label textarea automatically

### Delete question
- Context menu "Supprimer" → inline confirmation appears inside the card: "Supprimer cette question ?" with "Oui, supprimer" (destructive) + "Annuler" — no full modal
- Confirming removes card from list with 150ms fade-out

### Trigger type change
- Conditional field transition: 200ms `opacity 0 → 1` + `height 0 → auto` (CSS transition, not GSAP)

### Publish flow
- "Publier le formulaire" button → opens PublishModal
- "Un client" radio selected → client search field appears
- Typeahead search: debounced 300ms, searches coach's linked clients by name
- Selecting a client → chip appears, search field clears
- "Confirmer" → POST `/forms/coach/forms/:id/publish` + (if Un client) POST trigger for that client → close modal → redirect to `/coach/forms` → success toast

### Archive flow
- "Archiver" button → opens ArchiveModal
- "Archiver" in modal → PATCH form status → close modal → redirect to `/coach/forms` → success toast

### Auto-save (Claude's Discretion — optional)
- If implemented: debounced 2s after last edit, silent save indicator `text-xs text-muted` "Sauvegardé à HH:MM" in sticky header left of breadcrumb
- Not required for MVP — "Sauvegarder le brouillon" button is the primary save mechanism

## API Integration Reference

All API calls use the pattern from existing programs pages: `createClientSupabase()` to get session token → fetch with `Authorization: Bearer {token}` header → Hono API base URL from `EXPO_PUBLIC_API_URL`.

| Action | HTTP | Endpoint | Body |
|--------|------|----------|------|
| List forms | GET | `/forms/coach/forms` | — |
| Create form (draft) | POST | `/forms/coach/forms` | `{ title, questions[], trigger_config, status: "draft" }` |
| Save draft edits | PATCH | `/forms/coach/forms/:id` | `{ title?, questions?, trigger_config? }` |
| Publish form | POST | `/forms/coach/forms/:id/publish` | `{ target: "one" \| "all", client_id?: string }` |
| Archive form | PATCH | `/forms/coach/forms/:id` | `{ status: "archived" }` |

### Data shapes (for TypeScript interfaces):

```ts
type QuestionType = 'text' | 'scale' | 'yesno' | 'choice';

interface FormQuestion {
  id: string; // client-generated UUID
  type: QuestionType;
  label: string;
  choices?: string[]; // only for type === 'choice', min 2
}

type TriggerType = 'first_contact' | 'after_n_sessions' | 'fixed_date' | 'manual';

interface TriggerConfig {
  type: TriggerType;
  n_sessions?: number;   // for after_n_sessions
  fixed_date?: string;   // ISO 8601 date string, for fixed_date
}

interface CoachForm {
  id: string;
  title: string;
  questions: FormQuestion[];
  trigger_config: TriggerConfig;
  status: 'draft' | 'active' | 'archived';
  created_at: string;
}
```
