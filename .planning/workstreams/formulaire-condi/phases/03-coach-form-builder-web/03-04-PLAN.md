## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PublishModal → POST /forms/coach/forms/:id/publish | Bearer token required; sets form status to active |
| ArchiveModal → PATCH /forms/coach/forms/:id | Bearer token; RLS prevents archiving another coach's form |
| Client search typeahead → GET /coach/clients | Bearer token; only returns coach's own linked clients |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-08 | Spoofing | PublishModal confirm | mitigate | Authorization: Bearer accessToken on POST /publish; Hono validates coach ownership before status change |
| T-03-09 | Spoofing | ArchiveModal confirm | mitigate | Authorization: Bearer accessToken on PATCH; RLS on coach_forms prevents cross-coach archive |
| T-03-10 | Tampering | client_id in publish body | mitigate | client_id validated server-side against coach's linked clients; unlinked client_id returns 403 from Hono route |
| T-03-11 | Information Disclosure | client typeahead search | mitigate | GET /coach/clients returns only clients linked to authenticated coach; no cross-coach exposure |
| T-03-12 | Denial of Service | unbounded typeahead requests | accept | Debounced 300ms; results sliced to 8 items; coach's own client base is bounded |
| T-03-SC | Tampering | npm installs | accept | No new packages in this plan |
</threat_model>
