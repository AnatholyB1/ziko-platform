<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → POST /coach/forms | Untrusted JSON body: title, questions JSONB, trigger_config JSONB |
| client → POST /athlete/forms/:instanceId/submit | Untrusted answers array; athlete claims ownership of instanceId |
| Supabase RLS | Auth JWT enforces row-level isolation — API trusts userId from validated token only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-05 | Tampering | PATCH /coach/forms/:id — coach modifies another coach's form | mitigate | WHERE coach_id = userId in UPDATE; 404 returned if no row matched |
| T-01-06 | Elevation of Privilege | POST /athlete/forms/:instanceId/submit — athlete submits another athlete's instance | mitigate | WHERE athlete_id = userId AND id = :instanceId fetch before INSERT; 404 if mismatch |
| T-01-07 | Denial of Service | Unbounded questions[] or answers[] arrays in POST bodies | accept | v1.14 scope; Supabase JSONB storage handles large payloads; rate limiting is Vercel-level |
| T-01-08 | Repudiation | Double-submit of a form instance | mitigate | 409 returned when instance.status = 'submitted'; DB-level partial UNIQUE index on pending prevents duplicate pending instances (plan 01-01) |
| T-01-SC | Tampering | npm/pip package installs | accept | No new packages — routes/forms.ts uses only hono and @supabase/supabase-js already in package.json |
</threat_model>
