## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| `auth.users` (ziko + portfolio) -> ephemeral scratch files | Raw email addresses cross from live Postgres into locally-written JSON, outside the repo |
| Ephemeral scratch data -> committed `01-INVENTORY.md` | Only the reduced, masked/aggregate form of the PII may cross this boundary — the highest-risk step in the entire phase |
| Committed `01-INVENTORY.md` -> permanent git history | Once committed, this file is effectively permanent (per D-04, it must survive past ziko's eventual decommission in Phase 7) — any PII leak here is not easily reversible |

Enforced by Task 1's acceptance criteria (regex scan for unmasked email pattern must return zero matches) and Task 2's final full-file PII scan before commit. |
