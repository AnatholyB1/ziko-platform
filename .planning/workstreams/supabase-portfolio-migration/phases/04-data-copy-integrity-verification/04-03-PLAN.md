## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-10 | Tampering | TRUNCATE / COPY on portfolio tenants | mitigate | all write SQL from lib-data ziko_-only builders; REFERRERS_SQL guard; no CASCADE; assertWriteAllowed + --confirm-ref for portfolio; ziko target refused |
| T-4-11 | Information Disclosure | PAT / login-role password | mitigate | config objects not URLs; redactSecrets on every error; password dropped after connect; login roles deleted in finally; token only via env or gitignored file |

| T-4-13 | Tampering | push webhooks / updated_at triggers firing during load | mitigate | SET LOCAL replica verified by current_setting per table; fallback DISABLE TRIGGER USER in-transaction; post-load tgenabled assertion |

| T-4-15 | Repudiation | silent partial load | mitigate | per-table snapshot count = streamed rows = target count before COMMIT; report per run |
| T-4-16 | Information Disclosure | row data in logs/report | mitigate | names/counts only; assertReportSafe on the report; masked UUIDs; report default path gitignored |
| T-4-17 | Tampering | writes to ziko | mitigate | source client uses read_only login role and READ ONLY transaction; assertWriteAllowed refuses ziko as target |
