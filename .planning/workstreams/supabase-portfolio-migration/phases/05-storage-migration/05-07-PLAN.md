## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test harness -> target auth pool | creates and deletes real auth users on a shared project (smoke) |
| JWTs / service key -> child processes and .tmp fixture | credentials leave the orchestrator process |
| codemod patch -> working tree | temporary source modification during the run |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-5-27 | Spoofing | access tests run with service role | mitigate | allow/deny cases use publishable-key clients with signInWithPassword sessions; service client confined to setup/cleanup |
| T-5-28 | Tampering | leftover test users/objects on portfolio (tenant drift, Pitfall 9) | mitigate | finally-block cleanup + SQL assertion of zero leftovers; smoke mode performs no object writes |
| T-5-29 | Information Disclosure | JWTs/emails in fixture or report | mitigate | fixture under gitignored .tmp-*, deleted in finally; report through assertReportSafe; emails on example.com, never printed |
| T-5-30 | Tampering | codemod patch left applied | mitigate | apply only on a clean file list, reverse in finally, assert clean afterwards, exit 1 loudly otherwise |
| T-5-31 | Elevation of Privilege | full (write) mode against portfolio | mitigate | resolveAuthRun refuses full on portfolio and any mode on ziko; portfolio needs --confirm-ref |
