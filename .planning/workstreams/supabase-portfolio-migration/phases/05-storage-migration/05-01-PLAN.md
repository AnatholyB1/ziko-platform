<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| live ziko metadata -> generated artifacts | policy text and bucket config flow into SQL and scripts |
| object keys / DB rows -> reports | keys and rows can contain user ids and filenames (KYC, personal docs) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-01 | Tampering | rewritePolicy | mitigate | bucket ids replaced only inside quoted literals from the live list; unknown bucket_id literal throws; findStalePolicyRefs re-checks output |
| T-5-02 | Tampering / DoS | rekeyObjectName | mitigate | first-segment-only replacement; throw if source UUID appears elsewhere, so a mis-keyed object can never lock a user out silently |
| T-5-03 | Elevation of Privilege | targetBucketId / assertTargetBucket | mitigate | every write target must match ^ziko-[a-z0-9-]+$, preventing writes into portfolio's own buckets |
| T-5-04 | Information Disclosure | evaluators / maskObjectKey | mitigate | counts and hashed keys only; tests run assertReportSafe on every evaluator output |
| T-5-05 | Tampering | rewriteStorageUrls | mitigate | host anchored to <sourceRef>.supabase.co and bucket alternation from list; already-prefixed URLs untouched (idempotent) |
</threat_model>
