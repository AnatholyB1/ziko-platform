## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator terminal → merge write path | The human approval gate; the only thing standing between a committed report and 1,324 production writes |
| on-disk dataset clone → merge inputs | Content that may have drifted from what the human actually reviewed |
| dataset-supplied relative paths → filesystem reads | `record.image` / `record.gif_url` joined onto a real path |
| merge process → production Postgres + Storage | Service-role writes that bypass all RLS |
