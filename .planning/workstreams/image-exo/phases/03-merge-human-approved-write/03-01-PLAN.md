Then `CREATE INDEX IF NOT EXISTS idx_exercises_merge_backup_id ON public.exercises_merge_backup(id);` for later manual lookup by original exercise id.

Then `ALTER TABLE public.exercises_merge_backup ENABLE ROW LEVEL SECURITY;` with a comment mirroring `20260814_exercise_media_schema.sql` line 32: no policies means deny-by-default for anon/authenticated, and the service-role client used by `merge.ts` bypasses RLS.
