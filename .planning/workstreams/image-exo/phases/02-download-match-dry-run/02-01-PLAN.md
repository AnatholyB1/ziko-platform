Module-system constraint (hard rule for all Phase 2 plans):
  - Root package.json has NO "type" field, so tsx compiles these files as CommonJS while
    vitest transforms them as ESM. Therefore: NO `import.meta.url` and NO `__dirname`
    anywhere in `lib/**`. All paths are repo-root-relative string constants (lib/paths.ts)
    and every script must be run from the repo root.
  - Relative imports are extensionless (e.g. `./lib/normalize`), NOT `./lib/normalize.js`.
  - All testable logic lives in `lib/**`. `fetch.ts` and `match.ts` are thin entrypoints
    that call `main()` unconditionally at module load; tests never import them.
