## v1.13 Requirements — COMPLETED

### Upload Vidéo (Mobile)

- [x] **UPLOAD-01**: L'athlète peut sélectionner une vidéo depuis sa galerie OU enregistrer directement depuis la caméra via expo-image-picker — ✓ v1.13 (VideoUploadSheet: launchImageLibraryAsync + launchCameraAsync with mediaTypes: ['videos'])
- [x] **UPLOAD-02**: L'upload affiche une barre de progression (XMLHttpRequest avec events de progression — fichiers 50–500 MB) — ✓ v1.13 (XHR PUT with xhr.upload.onprogress, progress bar View with width: ${uploadProgress}%)
- [x] **UPLOAD-03**: L'athlète peut saisir un titre/label avant l'upload — ✓ v1.13 (auto-suggested title + required TextInput, Upload disabled when title empty)
- [x] **UPLOAD-04**: Le coach reçoit une notification push quand une nouvelle vidéo est disponible — ✓ v1.13 (notificationService.send() with idempotencyKey: video_uploaded_${videoId} in /complete endpoint)

### Infrastructure & Storage

- [x] **INFRA-01**: Bucket Supabase `coach-videos` créé avec RLS basée sur `is_coach_of()` — ✓ v1.13 (private bucket created via SQL insert into storage.buckets; 3 storage policies in migration 057)
- [x] **INFRA-02**: Vidéo exportée en H.264/MP4 via `videoExportPreset` — ✓ v1.13 (VideoExportPreset.H264_1920x1080 + allowsEditing: false in expo-image-picker call)
- [x] **INFRA-03**: Upload via signed URL PUT — Vercel 4.5 MB limit contournée — ✓ v1.13 (createSignedUploadUrl; video bytes never pass through Hono)
- [x] **INFRA-04**: Migration SQL `coach_client_videos` + `coach_video_annotations` — ✓ v1.13 (migration 057: both tables with full schema + 5 RLS policies)

### Player & Annotations Texte (Web)

- [x] **PLAYER-01**: Onglet "Vidéos" dans la vue client detail — ✓ v1.13 (11th tab in ClientTabStrip; VideoListClient with 4 states; ClientNotesPanelConditional hides notes panel on /videos/*)
- [x] **PLAYER-02**: Coach peut lire une vidéo via `@vidstack/react` — ✓ v1.13 (@vidstack/react@1.15.1; MediaPlayer + DefaultVideoLayout with scrubbing, playback speed, slow-motion)
- [x] **ANNOT-01**: Coach peut créer une annotation texte timecodée avec marker coloré sur la timeline — ✓ v1.13 (AnnotatedTimeSlider with orange dot overlay at timestamp % positions; "Annoter à ce moment" button)
- [x] **ANNOT-02**: Coach peut modifier ou supprimer ses annotations existantes — ✓ v1.13 (PATCH + DELETE routes with double-column ownership guard; inline edit/delete in AnnotationPanel)
- [x] **ANNOT-03**: Panel latéral avec annotations triées par timestamp, clic → seek — ✓ v1.13 (AnnotationPanel list sorted by timestamp_s; remote.seek(timestamp_s) on annotation click)

### Lecture Annotations (Mobile — Athlète)

- [x] **REVIEW-01**: L'athlète peut ouvrir ses vidéos et voir les markers d'annotations — ✓ v1.13 (VideoPlayerScreen with annotation timeline strip; orange dots at timestamp % positions; duration > 0 gate)
- [x] **REVIEW-02**: L'athlète peut tapper sur un marker pour seek et lire le commentaire — ✓ v1.13 (44×44px TouchableOpacity touch targets; player.currentTime = timestamp_s on tap; annotation list below player)

### Annotations Vocales (Web)

- [x] **VOICE-01**: Coach peut enregistrer un commentaire vocal via MediaRecorder Web API — ✓ v1.13 (VoiceComposer 5-state component; useVocalRecorder hook; mode toggle [Texte][Voix] in AnnotationPanel)
- [x] **VOICE-02**: Commentaire vocal transcrit via Whisper + nettoyé via Claude — route indépendante — ✓ v1.13 (POST /coach/videos/annotations/transcribe; lib/whisper.ts shared with v1.9 without modifying v1.9 route)
- [x] **VOICE-03**: Blob audio stocké dans `coach-videos/annotations/` + transcript en DB — ✓ v1.13 (storage path ${athlete_id}/annotations/${uuid}.ext; insertVoiceAnnotation with type='voice' + audio_path)
- [x] **VOICE-04**: Player audio accessible inline dans le panel d'annotations — ✓ v1.13 (<audio controls preload="none"> with signed URL; skeleton while URL loading; audioUrlMap cache)

## Out of Scope

| Feature | Raison |
|---------|--------|
| Retour vidéo webcam coach | Explicitement reporté v1.x+1 par décision utilisateur |
| Dark mode player | Light sport theme only — aucun dark mode dans Ziko |
| Transcoding pipeline | Vercel serverless incompatible avec FFmpeg — H.264 enforcement côté mobile |
| Side-by-side comparison | Complexité injustifiée pour 1:1 coaching en v1 |
| AI form detection / analyse posturale | Hors scope — annotation manuelle dans ce milestone |
