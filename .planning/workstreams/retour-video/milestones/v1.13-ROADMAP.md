## Overview

Three phases that build the video feedback pipeline from the ground up. Phase 45 lays the storage and upload foundation — Supabase `coach-videos` bucket, migration 057, and the two Hono endpoints that generate a signed PUT URL and register the upload completion. Phase 46 delivers the @vidstack/react web player with timecoded text annotation workflow: orange dot markers on the timeline scrub bar, 5-state AnnotationPanel with full CRUD, and a matching mobile VideoPlayerScreen via expo-video 3.0.16. Phase 47 adds the voice annotation pipeline: `lib/whisper.ts` extracted as a shared utility, VoiceComposer 5-state recording component on web, Whisper + Claude transcript cleaning route, inline `<audio controls>` player in the panel, and a mic badge on mobile.

The result is a complete 1:1 coach-to-athlete video feedback loop: athlete uploads a video from mobile → coach annotates with text and voice at specific timecodes → athlete reviews annotations synchronized with the video on mobile.

**Done criterion achieved:** Joaquim uploads a squat video from mobile → Guillaume annotates at T+1:23 with a cleaned voice comment visible in the lateral panel.

- [x] 45-02: Hono backend `/coach/videos/upload-url` + `/:videoId/complete` + vitest unit tests — commits ddc94b7, ec60bcb, 734325e
