  <action>
    Create supabase/migrations/057_coach_videos_schema.sql with the following structure (do NOT use a fenced code block — write the file directly):

    1. SET LOCAL lock_timeout = '5s';

    2. CREATE TABLE IF NOT EXISTS public.coach_client_videos with columns:
       - id UUID PRIMARY KEY DEFAULT gen_random_uuid()
       - athlete_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE
       - coach_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE
       - storage_path TEXT NOT NULL  (path convention: {athleteId}/{videoId}.mp4)
       - title TEXT NOT NULL CHECK (char_length(title) <= 200)
       - duration_s INTEGER (nullable — mobile may omit)
       - status TEXT NOT NULL DEFAULT 'ready' CHECK (status IN ('uploading', 'ready', 'annotated'))
       - created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()

    3. CREATE INDEX idx_coach_client_videos_athlete ON coach_client_videos(athlete_id, created_at DESC)
    4. CREATE INDEX idx_coach_client_videos_coach ON coach_client_videos(coach_id, created_at DESC)

    5. ALTER TABLE public.coach_client_videos ENABLE ROW LEVEL SECURITY

    6. RLS policies on coach_client_videos:
       - "coach_client_videos_athlete" FOR ALL: USING/WITH CHECK (auth.uid() = athlete_id)
       - "coach_client_videos_coach_read" FOR SELECT: USING (public.is_coach_of(auth.uid(), athlete_id))
       - "coach_client_videos_coach_update" FOR UPDATE: USING/WITH CHECK (auth.uid() = coach_id)

    7. CREATE TABLE IF NOT EXISTS public.coach_video_annotations with columns:
       - id UUID PRIMARY KEY DEFAULT gen_random_uuid()
       - video_id UUID NOT NULL REFERENCES public.coach_client_videos(id) ON DELETE CASCADE
       - coach_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE
       - timestamp_s NUMERIC(10,3) NOT NULL
       - type TEXT NOT NULL CHECK (type IN ('text', 'voice'))
       - content TEXT (nullable — voice annotation may have no initial content)
       - audio_path TEXT (nullable — text annotations have no audio)
       - created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()

    8. CREATE INDEX idx_coach_video_annotations_video ON coach_video_annotations(video_id, timestamp_s)

    9. ALTER TABLE public.coach_video_annotations ENABLE ROW LEVEL SECURITY

    10. RLS policies on coach_video_annotations:
        - "coach_video_annotations_coach" FOR ALL: USING/WITH CHECK (auth.uid() = coach_id)
        - "coach_video_annotations_athlete_read" FOR SELECT: USING (EXISTS (SELECT 1 FROM public.coach_client_videos v WHERE v.id = video_id AND v.athlete_id = auth.uid()))

    11. RLS policies on storage.objects (bucket coach-videos):
        - "coach_videos_athlete_upload" FOR INSERT WITH CHECK: bucket_id = 'coach-videos' AND auth.uid()::text = (storage.foldername(name))[1]
        - "coach_videos_athlete_read" FOR SELECT USING: bucket_id = 'coach-videos' AND auth.uid()::text = (storage.foldername(name))[1]
        - "coach_videos_coach_read" FOR SELECT USING: bucket_id = 'coach-videos' AND public.is_coach_of(auth.uid(), (storage.foldername(name))[1]::uuid)

    Note on storage.foldername: if this utility is unavailable in the project's Supabase version, use split_part(name, '/', 1) as equivalent fallback (per Assumption A3 in RESEARCH.md).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| storage.objects INSERT | Athlete directly PUTs bytes to Supabase signed URL — path ownership must be enforced by RLS |
| storage.objects SELECT | Coach reads athlete videos — is_coach_of() enforces link-based access |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-45-01 | Spoofing | storage.objects INSERT path | mitigate | RLS policy checks auth.uid()::text = (storage.foldername(name))[1] — athlete can only upload to their own subfolder |
| T-45-02 | Elevation of Privilege | coach_client_videos_coach_read | mitigate | RLS uses is_coach_of() which checks revoked_at IS NULL and expires_at — stale links rejected |
| T-45-03 | Spoofing | coach-videos bucket public exposure | mitigate | Bucket created as private — no anonymous or public access |
| T-45-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this plan — migration only |
</threat_model>
