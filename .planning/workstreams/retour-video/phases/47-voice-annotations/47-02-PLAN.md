Internal useReducer states (from D-03 + 047-UI-SPEC.md):
type VoiceState =
  | { status: 'idle' }
  | { status: 'recording' }
  | { status: 'transcribing' }
  | { status: 'review'; transcript: string; audioPath: string }
  | { status: 'error'; message: string }

Internal actions:
  | { type: 'START_RECORDING' }
  | { type: 'STOP_RECORDING' }
  | { type: 'TRANSCRIPTION_SUCCESS'; transcript: string; audioPath: string }
  | { type: 'TRANSCRIPTION_ERROR'; message: string }
  | { type: 'RESET' }  // Ré-enregistrer → back to idle

- elapsed timer: useState(0) + setInterval in recording state
- handleStart: await recorderStart(); dispatch START_RECORDING; start interval
- handleStop: const { blob, mimeType } = await recorderStop(); dispatch STOP_RECORDING; upload
- uploadBlob: FormData with 'audio' blob + 'mimeType' field; POST to transcribe endpoint; dispatch result
