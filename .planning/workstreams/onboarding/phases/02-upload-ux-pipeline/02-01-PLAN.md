**Helper functions** (inside the component):

1. `formatBytes(bytes: number): string` — returns `"X o"` / `"X Ko"` / `"X.X Mo"` (French byte units: o = octets, Ko = kilooctets, Mo = megaoctets). Use 1024 boundaries.

2. `getFileIcon(filename: string): JSX.Element` — returns `<IoDocumentOutline />` for `.pdf`, `<IoGridOutline />` for `.xlsx`/`.xls`, `<IoReaderOutline />` for `.docx`, `<IoDocumentOutline />` fallback. All icons: `className="w-5 h-5"`.

3. `handleFiles(fileList: FileList | null): void` — converts FileList to array via `Array.from()`, calculates `remaining = 4 - fileStates.length`, returns if `remaining <= 0`, slices incoming to `remaining`, creates `FileState[]` entries with `id: crypto.randomUUID()`, `status: 'uploading'`, appends to `fileStates` via `setFileStates(prev => [...prev, ...newStates])`.

4. `removeFile(id: string): void` — clears the interval from `intervalsRef.current` if present, deletes entry from map, filters out the file from `fileStates`.

5. Drag event handlers:
   - `handleDragOver(e: React.DragEvent)`: `e.preventDefault()`, `e.stopPropagation()`, `setIsDragOver(true)`.
   - `handleDragLeave(e: React.DragEvent)`: `e.preventDefault()`, `e.stopPropagation()`, `setIsDragOver(false)`.
   - `handleDrop(e: React.DragEvent)`: `e.preventDefault()`, `e.stopPropagation()`, `setIsDragOver(false)`, call `handleFiles(e.dataTransfer.files)`.
