## Component Contract: WizardStep4Import

**File:** `apps/web/src/components/coach/WizardStep4Import.tsx`

This is the only new UI surface in Phase 1. It must be visually indistinguishable from `WizardStep3Kyc` in structure.

### Prop Interface

```ts
{
  userId: string;
  apiUrl: string;
  jwt: string;
  onSuccess: () => void;
  onSkip: () => void;
}
```

Only `onSkip` is wired in Phase 1. All other props accepted but unused until Phase 2.

### DOM Structure

```
<div class="bg-white rounded-2xl p-8 border border-border shadow-sm">
  <h2 class="text-xl font-bold text-text mb-2">
    {t('step4Heading')}                  ← "Importer vos documents"
  </h2>
  <p class="text-sm font-normal text-muted mb-6">
    {t('step4Subtitle')}                 ← placeholder body (Claude's discretion)
  </p>

  <!-- placeholder body area: empty in Phase 1, filled Phase 2+ -->

  <div class="flex gap-3 mt-8 justify-end items-center">
    <button
      type="button"
      onClick={onSkip}
      class="h-11 px-4 text-sm font-normal text-muted hover:text-text transition-colors"
    >
      {t('step4Skip')}                   ← "Ignorer pour l'instant"
    </button>
    <!-- NO primary CTA button in Phase 1 -->
  </div>
</div>
```
