**Workstream:** onboarding

**Last updated:** 2026-08-13 (reconciled at milestone close)

---

## Active Requirements

### WIZARD — Intégration dans le wizard existant

- [x] **WIZARD-01**: Le coach voit 4 steps dans `WizardProgress` au lieu de 3
- [x] **WIZARD-02**: `WizardStep3Kyc.onSuccess` redirige vers `?step=4` au lieu du dashboard
- [x] **WIZARD-03**: `OnboardingWizard` monte `WizardStep4Import` quand `step === 4`

### UPLOAD — Upload de fichiers

- [x] **UPLOAD-01**: Le coach peut uploader jusqu'à 4 fichiers (PDF, Excel, Word) depuis Step 4
- [x] **UPLOAD-02**: L'IA ouvre la conversation avec un message d'invite explicite ("Envoie-moi tes docs…")
- [x] **UPLOAD-03**: Chaque fichier sélectionné déclenche automatiquement le pipeline Phase 28 (create → upload → status → parse)

### PARSE — Orchestration et classification IA

- [x] **PARSE-01**: L'IA identifie le type de chaque doc parsé (DA coach / template programme / données client)
- [x] **PARSE-02**: L'IA affiche un résumé de ce qu'elle a compris pour chaque doc analysé
- [x] **PARSE-03**: L'IA pose une question de clarification si le type d'un doc est ambigu

### REVIEW — Confirmation avant commit

- [x] **REVIEW-01**: Le coach voit un résumé consolidé de tous les docs analysés avant toute action définitive
- [x] **REVIEW-02**: Le coach peut corriger le type d'un doc (ex : "c'est un template, pas une DA")
- [x] **REVIEW-03**: Les docs de type `coach_template` sont commités via `PUT /coach/imports/:id/commit` après confirmation

### COMPLETE — Fin de step

- [x] **COMPLETE-01**: Un bouton "Ignorer pour l'instant" permet de quitter Step 4 et d'aller au dashboard sans importer
- [x] **COMPLETE-02**: Après confirmation et commit, le coach est redirigé vers `/coach/dashboard`
