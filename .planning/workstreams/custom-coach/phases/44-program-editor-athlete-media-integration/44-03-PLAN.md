# Plan 44-03: ExerciseTypeahead — custom badge + coach_exercise_id passthrough

## Objective

Update `ExerciseTypeahead.tsx` to handle the extended API response (now includes `source` and `coach_exercise_id` fields), render a "Custom" badge for coach-custom results, and pass `coach_exercise_id` through `AddedExercise` when a custom exercise is selected.

## must_haves

### truths
- `ExerciseResult` interface gains `source?: "global" | "coach_custom"` and `coach_exercise_id?: string | null`
- `AddedExercise` interface gains `coach_exercise_id?: string | null`
- `selectResult()` sets `coach_exercise_id: result.coach_exercise_id ?? null` in the `onAdd()` call
- "Custom" badge rendered for results where `result.source === "coach_custom"`: exact classes `bg-primary/10 text-primary` chip, text "Custom", placed right-aligned on the same row as the exercise name (after the category chip)
- Custom results appear before global results (backend controls order — no frontend re-sort)
- Keyboard navigation (ArrowUp/Down/Enter/Escape) unchanged
- Inline "Créer l'exercice" create-from-query button unchanged — still creates in global `exercises` table via `POST /programs/exercises`

### verification_commands
- `rtk tsc --noEmit` exits 0 in `apps/web/`
- Dropdown item for `source: "coach_custom"` has a visible `<span>Custom</span>` with classes `bg-primary/10 text-primary`

### Task 2 — Update `selectResult()` to pass `coach_exercise_id`

<read_first>
- `apps/web/src/components/coach/ExerciseTypeahead.tsx` lines 103–109 — `selectResult()` function and `onAdd()` call
</read_first>

<action>
In `selectResult(result: ExerciseResult)`, update the `onAdd()` call:
```ts
onAdd({
  exercise_id: result.source === 'coach_custom' ? null : result.id,
  exercise_name: result.name,
  category: result.category,
  coach_exercise_id: result.coach_exercise_id ?? null,
});
```

Note: When `source === "coach_custom"`, `exercise_id` is null (no row in global `exercises` table). `coach_exercise_id` carries the identifier per D-05/D-06.
</action>

<acceptance_criteria>
- `selectResult()` passes `coach_exercise_id: result.coach_exercise_id ?? null` in the `onAdd()` call
- When `source === 'coach_custom'`, `exercise_id` is `null`
- When `source === 'global'` or `source` is undefined, `exercise_id` is `result.id` (existing behavior)
- `rtk tsc --noEmit` exits 0
</acceptance_criteria>
