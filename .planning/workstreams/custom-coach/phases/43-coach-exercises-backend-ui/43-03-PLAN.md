      onVideoRemoved: () => void; onPhotoRemoved: () => void; disabled?: boolean }

    Two upload rows — video and photo. Each row is independent (separate state: idle | uploading | done | error).

    Upload logic (same for both):
    1. Validate type + size (video max 100MB, photo max 10MB); set error on failure
    2. GET /api/storage/upload-url?bucket=coach-exercises&path={userId}/{Date.now()}-{file.name} with Authorization Bearer jwt
    3. Use XMLHttpRequest for progress tracking: xhr.upload.addEventListener('progress', e => setProgress(Math.round(e.loaded/e.total*100)))
    4. On completion: supabase.storage.from('coach-exercises').uploadToSignedUrl(path, token, file)
    5. On success: call onVideoUploaded(path) or onPhotoUploaded(path)
    6. Store path (not signed URL)

    Progress bar: h-1 bg-border rounded-full container + bg-primary rounded-full transition-all width={progress+'%'}
    Success state: IoCheckmarkCircle className="text-success text-lg" + filename + remove button
    Error state: IoAlertCircle red + error text + "Réessayer" link (text-primary underline)

    Section label above rows: text-xs font-bold text-muted uppercase tracking-wide mb-3 — "MÉDIAS DE DÉMO"

    Video row accepts: video/mp4,video/quicktime,video/webm. Label "Ajouter une vidéo", icon IoVideocam.
