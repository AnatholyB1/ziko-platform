## Completed Requirements

### Bibliothèque d'exercices custom (EXLIB)

- [x] **EXLIB-01:** Coach peut créer un exercice custom avec nom, description, muscles ciblés et catégorie
  - *Outcome: Validated — ExerciseSlideOver form creates exercises via POST /coach/exercises*

- [x] **EXLIB-02:** Coach peut uploader une vidéo de démo attachée à un exercice custom (Supabase Storage, bucket `coach-exercises`)
  - *Outcome: Validated — ExerciseMediaUpload uploads via XHR to signed URL, stores path in coach_exercises.video_path*

- [x] **EXLIB-03:** Coach peut uploader une photo de démo attachée à un exercice custom (même bucket)
  - *Outcome: Validated — same ExerciseMediaUpload component handles photo row (jpeg/png/webp, 10MB)*

- [x] **EXLIB-04:** Coach peut éditer et supprimer ses exercices custom
  - *Outcome: Validated — PATCH /:id and DELETE /:id routes; delete removes storage files before DB row*

- [x] **EXLIB-05:** Exercices custom du coach disponibles dans le typeahead de l'éditeur de programme (fusionnés avec la bibliothèque globale, distingués visuellement)
  - *Outcome: Validated — searchExercises merges both tables; ExerciseTypeahead renders "Custom" badge (bg-primary/10)*

- [x] **EXLIB-06:** L'athlète voit la vidéo/photo de démo quand il consulte un exercice dans son programme
  - *Outcome: Validated — workout/[id].tsx pageSheet modal with expo-av video + react-native Image; graceful no-media fallback*

### Audit vue client (AUDIT)

- [x] **AUDIT-01:** Vérifier et garantir que le coach voit les programmes créés par l'athlète dans la vue client detail (Phase 26 coverage check — fix si absent)
  - *Outcome: Fixed — getProgramsForClient coach filter removed; returns { active, history } for all programs*
