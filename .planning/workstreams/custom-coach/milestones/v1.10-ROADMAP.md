# Archived Roadmap: v1.10 Custom Coach Exercises

## Summary

Coaches can now create and manage a custom exercise library (with video/photo demos) from the web CRM. Custom exercises appear alongside global ones in the program editor typeahead. Athletes see demo media inline when reviewing their program exercises on mobile.

## Accomplishments

1. **Phase 42 — Audit Client Programs Visibility**: Fixed `getProgramsForClient` to remove the coach-side filter and return `{ active, history }` — athlete-created programs now appear in the coach's client detail view alongside coach-assigned programs.

2. **Phase 43-01 — DB Foundation**: Provisioned `coach_exercises` table (PostgreSQL + RLS: `auth.uid() = coach_id`) and private `coach-exercises` Supabase Storage bucket with per-uid prefix policies. ALLOWED_BUCKETS updated in both Next.js and Hono upload-url endpoints.

3. **Phase 43-02 — Hono CRUD Backend**: Full CRUD module (`types.ts`, `db.ts`, `service.ts`) for coach exercises — create, list, patch, delete with storage cleanup on delete. IDOR-guarded by JWT-derived `coachId`.

4. **Phase 43-03 — Web UI Atoms**: `MuscleChipSelector` (11 toggle chips, aria-pressed), `ExerciseMediaUpload` (video + photo with real XHR progress), `ExerciseRow` (6 states, inline delete confirm). `CoachExercise` type created in `apps/web/src/types/coach.ts`.

5. **Phase 43-04 — Exercises Page**: Complete `/coach/exercises` page — `ExerciseSlideOver` drawer (GSAP shake validation, ARIA, Escape key), `ExercisesClient` (filter pills, GSAP stagger), server component with auth guard. CoachSidebar updated with Exercices nav item.

6. **Phase 44-01 — Backend Merge**: `searchExercises()` queries both `exercises` and `coach_exercises`, returning merged results with `source: "global" | "coach_custom"`. Custom items float first (alphabetical).

7. **Phase 44-02 — Migration + Signed URL Endpoint**: Added `program_exercises.coach_exercise_id` FK migration. New `GET /coach/exercises/:id/media-url` endpoint validates `coach_client_links` relationship, then generates 3600s signed URLs via admin Supabase client. Graceful null degradation on missing relationship or media.

8. **Phase 44-03 — ExerciseTypeahead Badge**: Extended `ExerciseTypeahead` with `source` + `coach_exercise_id` passthrough. "Custom" badge rendered in dropdown (bg-primary/10, text-primary).

9. **Phase 44-04 — Athlete Media Modal**: `workout/[id].tsx` now includes a `pageSheet` modal with `expo-av` video player and react-native Image for photo — triggered by tapping any exercise row with a `coach_exercise_id`. Graceful no-media fallback.
