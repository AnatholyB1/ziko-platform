## Shipped Requirements

### VOICE — Enregistrement & Transcription

- [x] **VOICE-01**: Coach peut démarrer/arrêter un enregistrement audio (mic browser, max 5 min) depuis la fiche client web CRM
  - _Outcome: VocalIdle + VocalRecording + useVocalRecorder + useVocalTimer. Tab "Retour vocal" (9th tab) in ClientTabStrip. Validated: Phase 01 (01-04, 01-05)_
- [x] **VOICE-02**: Audio uploadé au serveur et transcrit via OpenAI Whisper API (`whisper-1`, FR/EN)
  - _Outcome: POST /coach/voice/transcribe via voiceRouter. arrayBuffer proxy for binary safety. Validated: Phase 01 (01-02, 01-03)_
- [x] **VOICE-03**: Transcript affiché en lecture seule avant la structuration — le coach peut valider ou relancer
  - _Outcome: VocalReview component with Valider/Relancer buttons; GSAP shake on error. Validated: Phase 01 (01-05)_

### STRUCT — Structuration Claude

- [x] **STRUCT-01**: Claude reçoit le transcript + contexte complet de l'athlète : dernières 10 séances (poids, reps, RPE), mesures récentes, scores sommeil, notes coach privées, historique feedbacks vocaux
  - _Outcome: POST /voice/structure assembles full athlete context via Promise.all (sessions, measurements, sleep, notes, vocal_history). Validated: Phase 02 (02-02)_
- [x] **STRUCT-02**: Output : card structurée en 5 sections — Contexte séance, Points forts, Corrections, Next steps, Tags automatiques (force / technique / mental / cardio / récupération)
  - _Outcome: Claude generateObject → StructuredCard schema. TagChip (5 tags), CardSection (4 sections). Validated: Phase 02 (02-04)_
- [x] **STRUCT-03**: Coach peut éditer la card avant de sauvegarder
  - _Outcome: CardSection click-to-edit, inline textarea, TAG_TOGGLE dispatch. Local useState for active section. Validated: Phase 02 (02-03, 02-04)_

### MEM — Mémoire long terme

- [x] **MEM-01**: Feedback structuré sauvegardé en base (`coach_vocal_feedbacks`) avec timestamp, athlète, transcript brut et card JSON
  - _Outcome: Migration 20260527_coach_vocal_feedbacks.sql + POST /voice/save + real frontend save wiring + SAVE_ERROR retry UX. Validated: Phase 03 (03-01, 03-03), UAT test 2_
- [x] **MEM-02**: Les N feedbacks précédents de l'athlète sont injectés dans le contexte Claude lors de la structuration (mémoire long terme)
  - _Outcome: Last 3 feedbacks queried from coach_vocal_feedbacks and injected into buildStructuringPrompt. N=3 hardcoded. Validated: Phase 03 (03-02), UAT test 8_
- [x] **MEM-03**: Historique des feedbacks vocaux accessible depuis la fiche client (onglet dédié ou section)
  - _Outcome: VocalFeedbackHistory component — date (fr-FR), tag chips, 100-char context preview, inline expand (one row at a time). Validated: Phase 03 (03-03), UAT tests 4-7_

## Deferred (post-v1.9)

- Partage du feedback à l'athlète (email ou notification push)
- Synthèse mensuelle automatique par athlète
- Cross-context coach (comparaison inter-athlètes) — scope trop large
- Export PDF du feedback

## Out of Scope

- Mobile coach (Expo) — surface web uniquement
- Commandes vocales (STT pour interface) — différent du retour vocal coach
- Temps réel (streaming Whisper) — batch upload suffit
- Groq/Vercel AI SDK Whisper — OpenAI Whisper API direct retenu
