**Total Plans:** 12

## Overview

Le coach peut enregistrer un retour vocal sur un athlète depuis la fiche client web. Whisper transcrit l'audio, Claude reçoit le transcript + le contexte complet de l'athlète et produit une card structurée en 5 sections éditable inline. Le feedback est persisté en base avec RLS, et les N derniers feedbacks sont injectés dans le contexte Claude lors des structurations suivantes.

**Done criterion met:** Guillaume peut faire son premier retour vocal sur Joaquim et recevoir une card structurée exploitable.

## Milestone Summary

### Key Decisions

| Decision | Rationale |
|----------|-----------|
| OpenAI Whisper API direct (not Groq/Vercel AI SDK) | Retenu pour fiabilité FR/EN; streaming batch suffit |
| req.arrayBuffer() pour multipart | Evite la corruption binaire audio (boundary preserved) |
| RESET sans garde d'état | Toujours autorisé depuis n'importe quel état |
| SECTION_EDIT + TAG_TOGGLE acceptent card-ready ET card-editing | Inline edit possible sans transition d'état intermédiaire |
| Active edit section via local useState (pas reducer) | Pas de round-trip reducer pour l'état UI local |
| coach_id depuis JWT (jamais du body) | RLS enforce coach ownership, pas d'injection possible |
| N=3 feedbacks injectés dans Claude context | Balance entre contexte riche et tokens |
| Loader2 GSAP dans span wrapper (pas SVG ref) | Evite TS2322 Ref incompatibilité entre modules React |

### Issues Resolved

- Binary proxy bug silently corrupting Whisper audio → fixed with arrayBuffer passthrough
- TypeScript Ref<SVGSVGElement> incompatibilité Loader2 → span wrapper
- card-saving state missing `card` field → added to union, VocalCardReady discriminates correctly
- TypeScript narrowing échec dans async closure → captured `editedCard` avant closure
- vocalReducer.test.ts fixture stale après extension type → auto-fixed in 03-03

### Issues Deferred (post-v1.9)

- Partage du feedback à l'athlète (email ou notification push)
- Synthèse mensuelle automatique par athlète
- Cross-context coach (comparaison inter-athlètes)
- Export PDF du feedback

### Technical Debt

- Fake save timeout removed (03-03), but no optimistic update UX (reload required to see history)
- N=3 hardcoded in memory injection — should be configurable per coach preference
