    - Filename passed to toFile derives from mimeType: 'recording.mp4' if mimeType includes 'mp4', else 'recording.webm'
    - On OpenAI API error → 500 { error: message } with console.error log

    Replace the 501 stub handler body in the `POST /transcribe` handler with the full implementation:

    1. Parse body: `const body = await c.req.parseBody()`
    2. Extract and validate fields:
       - `const audioFile = body['audio']` — if `!(audioFile instanceof File)` → return 400 `{ error: 'audio field is required' }`
       - `const mimeType = (body['mimeType'] as string) ?? 'audio/webm'`
       - Validate mimeType against whitelist `['audio/webm', 'audio/webm;codecs=opus', 'audio/mp4']` — if not in whitelist → return 400 `{ error: 'Unsupported audio format. Use webm or mp4.' }`
