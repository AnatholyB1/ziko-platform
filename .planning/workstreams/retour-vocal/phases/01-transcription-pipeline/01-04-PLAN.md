// vocalReducer.ts exports:
type VocalState =
  | { status: 'idle' }
  | { status: 'recording'; startedAt: number }

  | { status: 'review'; transcript: string }
  | { status: 'error'; blob: Blob; mimeType: string; message: string };

  | { type: 'START_RECORDING' }

  | { type: 'TRANSCRIPTION_ERROR'; message: string }
  | { type: 'RETRY' }
  | { type: 'RELAUNCH' }
  | { type: 'VALIDATE' };

function vocalReducer(state: VocalState, action: VocalAction): VocalState

    - When active=false: resets elapsedSeconds to 0, clears interval
    - Returns { elapsedSeconds, formatted }

| browser mic API | getUserMedia requires HTTPS (secure context); mic permission prompt is OS-level |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06 | DoS | Audio blob size | mitigate | Client-side `blob.size > 4_000_000` guard logs console.warn; Vercel 4.5MB hard limit provides the actual enforcement |
| T-01-07 | Information Disclosure | clientId in VocalRetourPanel props | accept | clientId is a UUID passed from the coach's own authenticated session; not sensitive on the client surface |
