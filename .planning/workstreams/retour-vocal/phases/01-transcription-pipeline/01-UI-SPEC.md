## Motion Design

> Personality: Snappy + Fluid hybrid — from MOODBOARD.md
> Entrances: 200ms `power2.out`
> Interactive feedback: 100ms `power3.out`
> Web: CSS transitions preferred; GSAP for complex sequences.

| Trigger | Animation | Duration | Easing | CSS/GSAP Pattern |
|---------|-----------|----------|--------|------------------|
| Page load → idle | Fade in + slight up | 200ms | power2.out | `gsap.from(".vocal-panel", { y: 16, opacity: 0, duration: 0.2, ease: "power2.out" })` |
| idle → recording (button press) | Button scale feedback | 100ms | power3.out | `gsap.to(btn, { scale: 0.94, duration: 0.1, yoyo: true, repeat: 1 })` then state switch |
| idle → recording (state transition) | Panel crossfade | 200ms | power2.inOut | `gsap.to(".vocal-panel", { opacity: 0, duration: 0.1 })` then swap content then `gsap.from` reverse |
| Recording pulse ring | Continuous sine pulse on stop button | 1500ms | sine.inOut | `@keyframes pulse-ring { 0% { box-shadow: 0 0 0 0 rgba(239,68,68,0.4) } 100% { box-shadow: 0 0 0 20px rgba(239,68,68,0) } }` — 1.5s infinite |
| Timer tick | Color transition (normal → red) at 4:00 | 500ms | power2.out | CSS `transition: color 500ms ease` |
| recording → transcribing | State crossfade | 200ms | power2.inOut | Same pattern as idle→recording |
| Spinner rotation | Continuous spin | 800ms | linear | `@keyframes spin { to { transform: rotate(360deg) } }` — 0.8s linear infinite |
| transcribing → review | Transcript block entrance | 250ms | power2.out | `gsap.from(".transcript-block", { y: 12, opacity: 0, duration: 0.25, ease: "power2.out" })` |
| transcribing → review-error | Error block entrance | 200ms | power2.out | `gsap.from(".error-block", { y: 8, opacity: 0, duration: 0.2, ease: "power2.out" })` then shake |
| Error shake | Error block horizontal shake | 300ms | none | `gsap.to(".error-block", { keyframes: { x: [-6, 6, -4, 4, -2, 2, 0] }, duration: 0.3 })` |
| [Valider] press | Button scale feedback | 100ms | power3.out | `gsap.to(btn, { scale: 0.97, duration: 0.1, yoyo: true, repeat: 1 })` |
| [Relancer] press | Button scale feedback | 100ms | power3.out | Same as [Valider] press |
| review → idle (Relancer) | Panel crossfade | 200ms | power2.inOut | Same crossfade pattern, content returns to idle |
| review-error → transcribing (Ressayer) | Crossfade to spinner | 200ms | power2.out | Same crossfade pattern |

## Implementation Notes for Executor

### Component Structure

```
apps/web/src/app/[locale]/(coach)/coach/clients/[id]/vocal/
  page.tsx           ← thin server wrapper (imports VocalRetourPanel)

apps/web/src/components/coach/vocal/
  VocalRetourPanel.tsx    ← state machine root ('use client')
  VocalIdle.tsx           ← idle state view
  VocalRecording.tsx      ← recording state view + timer logic
  VocalTranscribing.tsx   ← spinner state view
  VocalReview.tsx         ← review + error sub-state view
  useVocalRecorder.ts     ← MediaRecorder hook (blob management)
  useVocalTimer.ts        ← mm:ss timer hook (setInterval, cleanup on unmount)
```

### State Machine Type

```ts
type VocalState =
  | { status: 'idle' }
  | { status: 'recording'; startedAt: number }
  | { status: 'transcribing'; blob: Blob }
  | { status: 'review'; transcript: string }
  | { status: 'error'; blob: Blob; message: string }
```

### beforeunload Guard

```ts
useEffect(() => {
  if (state.status !== 'recording') return;
  const handler = (e: BeforeUnloadEvent) => {
    e.preventDefault();
    e.returnValue = 'Enregistrement en cours. Quitter annulera le retour.';
  };
  window.addEventListener('beforeunload', handler);
  return () => window.removeEventListener('beforeunload', handler);
}, [state.status]);
```

### Timer Color Logic

```ts
const timerColor = elapsedSeconds >= 240
  ? '#EF4444'   // red at 4:00+
  : '#6B6963';  // muted default
```

### Max Duration Enforcement

```ts
// Auto-stop at 5:00 (300 seconds)
if (elapsedSeconds >= 300) {
  stopRecording(); // triggers upload → transcribing state
}
```
