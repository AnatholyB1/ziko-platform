## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP body → Hono handler | Untrusted JSON: athlete_id and transcript come from the browser |
| Coach JWT → Supabase | Coach-issued JWT; RLS verifies coach-client relationship at DB level |
| Supabase data → Claude prompt | Athlete data assembled server-side; injected as plain text, not as instructions |
| Claude output → JSON response | generateObject + Zod schema validates shape before it reaches the wire |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02-01 | Elevation of Privilege | POST /voice/structure | mitigate | authMiddleware already mounted via voiceRouter.use('*', authMiddleware); RLS is_coach_of() enforces coach-client access at Supabase level |
| T-02-02-02 | Tampering | transcript → Claude prompt | mitigate | Transcript injected as plain text data block; generateObject with strict Zod schema cannot be manipulated to return a different JSON shape |
| T-02-02-03 | Denial of Service | Large transcript payload | mitigate | MAX_TRANSCRIPT_LENGTH = 10_000 char guard returns 400 before Claude call; Vercel 4MB body limit applies at edge |
| T-02-02-04 | Information Disclosure | Athlete data in Claude API call | accept | Data is already accessible to coach via Supabase RLS; Claude API traffic is HTTPS; no PII beyond what coach already sees |
| T-02-02-SC | Tampering | npm/pip installs | accept | No new packages — all imports are pre-existing project dependencies; no slopcheck required |
