## Critical Gap

### GAP-01 — BLOCKER — COACH-04: coach not in plugins_registry

**Severity:** BLOCKER  
**Requirement:** COACH-04 — mandatory trash button grayed out with tooltip in plugin store

**Root cause:**  
`apps/mobile/app/(app)/store/[id].tsx:73-78` fetches the manifest from `plugins_registry` DB table. The coach plugin was never inserted into `plugins_registry` (no seed.sql entry, no migration). Without a DB row, `manifest = null` → the screen shows an infinite loading spinner → `manifest.mandatory` check at line 257 is never reached.

**Fix:** Add coach plugin to `supabase/seed.sql` or create a new migration inserting the coach plugin row with `"mandatory": true` in the JSONB manifest field, matching the pattern used by the other 17 registered plugins.
