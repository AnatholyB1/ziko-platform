## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-01 | Tampering | `PluginManifest.mandatory` field | accept | Field is set only in static manifest files checked into source control; no runtime mutation path |
| T-27-02 | Elevation of Privilege | PluginLoader mandatory bypass | accept | Mandatory loading is unconditional for all authenticated users — no privilege escalation; coach plugin State A handles unauthenticated / no-coach-linked case |
| T-27-03 | Denial of Service | Manifest load failure in mandatory loop | mitigate | try/catch around each loader call with console.warn; failure of one mandatory plugin does not block others or the regular user_plugins load |
</threat_model>
