## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Model structured output → immutable decision journal | `decideWeeklyFocus`'s output becomes a permanent `athlete_decisions` row; anything trusted verbatim here is unfalsifiable afterwards |
| Interactive chat orchestrator → `create_goal` / `create_program` | Registering these tools in `allToolSchemas` newly exposes state-mutating tools to the general `/ai/chat` loop |
| Weekly engine → billing surface | Cost accounting must land on the opex side and never touch the athlete's credit balance |
