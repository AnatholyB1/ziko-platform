<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mobile client → `GET /coaching-engine/review-check` | The client can trigger backend AI work; the endpoint is authenticated but callable at will |
| Mobile client → `athlete_state` via PostgREST | The overlay reads coaching state directly under RLS rather than through a backend route |
| MMKV `weekly_review_seen` marker | Local, unsigned, athlete-writable device state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-31 | Information Disclosure | Overlay reading `athlete_state` | mitigate | The query goes through the RLS-scoped anon client with the athlete's own session; `athlete_state_select_own` restricts it to their own row. No service key is ever present on the device. |
| T-44-32 | Denial of Service / cost abuse | Repeated `/review-check` calls from a modified client | mitigate | The route does no model work itself, and `runWeeklyReview` short-circuits on `not_due` / `already_recorded` before any model call (plan 44-04, T-44-19). Worst case is one cheap indexed read per call. |
| T-44-33 | Tampering | `weekly_review_seen` MMKV marker | accept | The marker only controls whether a celebratory overlay re-displays. Tampering re-shows or suppresses a purely presentational moment; it cannot alter `athlete_state`, decisions, goals or rewards, all of which are RPC-gated server side. No PII and no authorization decision depends on it. |
| T-44-34 | Repudiation | Overlay rendering a stale or partial review | mitigate | The visibility gate requires a non-null `last_review_at` AND a non-empty `current_focus_summary` AND a marker mismatch; anything else renders nothing, so a pending or failed background review is invisible rather than shown as broken or misleading UI |
| T-44-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this plan — 44-RESEARCH.md's Package Legitimacy Audit records zero new external packages for the phase. |
</threat_model>
