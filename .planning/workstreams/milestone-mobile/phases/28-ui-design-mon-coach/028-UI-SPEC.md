## Spacing Scale

All values are multiples of 4. Applied as inline style numeric values (React Native points = dp = logical pixels).

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4 | Icon-to-label gap, chip internal horizontal padding |
| sm | 8 | Between chips, input inner vertical padding |
| md | 16 | Card inner padding, section spacing, CTA vertical padding |
| lg | 24 | Between card and CTA, top header margin |
| xl | 32 | Between major sections |
| 2xl | 48 | — (reserved, not used in this phase) |
| 3xl | 64 | — (reserved, not used in this phase) |
| tab-clearance | 100 | paddingBottom on ScrollView contentContainerStyle |

Exceptions:
- Touch targets (CTA button, "Retour à la saisie" link, "Retirer ce coach"): minimum 44 height enforced
- Code input field height: 56 (14-base grid exception for comfortable thumb target)
- Coach avatar: 72×72 (circle, not on 8-point grid — based on card layout requirement)
- KYC badge icon: 16×16 with 4px gap to label text
- `padding: 12` — 3×4, used for tight error message containers and modal text input (acceptable density exception)
- `gap: 12` — 3×4, used for modal button row spacing (acceptable density exception)
- `marginTop: 12` — 3×4, used for intra-card element spacing (chips row, bio, "Lié depuis" row, cancel link) (acceptable density exception)
- `marginLeft: 12` — 3×4, used for avatar right-column offset (acceptable density exception)
- `marginRight: 12` — 3×4, used for icon-to-text gap in settings row (acceptable density exception)

## Typography

All font sizes in React Native points. No `StyleSheet` — use inline `style` prop.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Display | 28 | 700 | 1.2 (≈34) | Screen title "Mon coach" + code input field |
| Heading | 20 | 700 | 1.2 (≈24) | Coach name in State B/C card |
| Body | 16 | 400 | 1.5 (≈24) | Input placeholder, bio text, error messages |
| Label | 14 | 400 | 1.4 (≈20) | CTA button label, specialty chips, metadata ("Lié depuis"), KYC badge label, muted subtitles |

Rules:
- Exactly 2 weights in use: 400 (regular) and 700 (bold). No other weights.
- CTA button labels (submit, confirm) use size 16 weight 700 color `#FFFFFF`.
- KYC badge, muted subtitles, chip text: size 14 weight 400 color `#6B6963` — visually distinguished from action labels by muted color alone.
- "Retour à la saisie" cancel link: 14px weight 400, color `#FF5C1A` (accent), not underlined.

## Interaction Contract

### Code Input (State A)

| Event | Behavior |
|-------|----------|
| `onChangeText` | Strip chars not in `[A-Z2-9]`, uppercase remaining, max 6 chars |
| Paste | `onChangeText` handles paste — same filter applied |
| 6 valid chars reached | Submit CTA transitions enabled (color `#FF5C1A`) |
| < 6 chars | Submit CTA disabled (color `#E2E0DA`) |
| Submit tap (enabled) | Show loading state → call `GET /coach/clients/links/preview?code=XXXXXX` |
| API returns 200 | Transition to State B (coach preview) |
| API returns 404/410/any error | Show constant-time error message — same copy regardless of error code |
| Keyboard dismiss | Input loses focus, border returns to `#E2E0DA` |

### Coach Preview (State B)

| Event | Behavior |
|-------|----------|
| "Lier mon compte" tap | Call `POST /coach/clients/links` with code → on success transition to State C |
| Loading state | CTA shows `ActivityIndicator` white, disabled |
| "Retour à la saisie" tap | Clear input, reset error, return to State A (clear code from state) |
| API error on confirm | Show error via `showAlert(t('coach.error.link_failed'), t('coach.error.try_again'))` |

### Linked Coach (State C)

| Event | Behavior |
|-------|----------|
| "Retirer ce coach" tap | Open ConfirmRevocationModal |
| Modal "Garder mon coach" | Close modal, no action |
| Modal input ≠ "COACH" | "Confirmer" button disabled |
| Modal input === "COACH" | "Confirmer" button enabled (red) |
| "Confirmer" tap | Call `DELETE /coach/clients/links/:id` → on success: close modal, transition to State A, clear local coach state |
| API error on revoke | Close modal, show `showAlert(t('coach.error.revoke_failed'), t('coach.error.try_again'))` |

### Pull-to-refresh (all states)
- `RefreshControl tintColor: '#FF5C1A'`
- Re-fetches current link status from backend
- Can transition between states if backend state changed externally
