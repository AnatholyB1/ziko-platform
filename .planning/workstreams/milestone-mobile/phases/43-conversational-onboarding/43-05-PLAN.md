    `{ messages: [{ role:'user', content }], conversation_id, locale }` with the

    - `meta` → store `conversation_id` in local state so subsequent turns and a relaunch resume reuse it.
    - `chunk` → append to the streaming buffer and update the in-flight assistant bubble.

| Boundary | Description |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
