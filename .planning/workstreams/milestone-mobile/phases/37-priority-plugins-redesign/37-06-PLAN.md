friendships table (migration 009): id, requester_id UUID, addressee_id UUID, status ('pending'|'accepted'|'blocked'), created_at, updated_at.
Friend query (must use both columns):
  supabase.from('friendships')
    .select('requester_id, addressee_id')
    .or(`requester_id.eq.${userId},addressee_id.eq.${userId}`)
    .eq('status', 'accepted')
  Then: friendIds = data.map(f => f.requester_id === userId ? f.addressee_id : f.requester_id)

workout_sessions JOIN (requires RLS policy from Wave 0):
  supabase.from('workout_sessions')
    .select('id, name, user_id, started_at, total_duration_seconds, user_profiles!inner(name)')
    .in('user_id', friendIds)
    .order('started_at', { ascending: false })
    .limit(20)

challenge_participants query (research Q3):
  supabase.from('challenge_participants')
    .select('score, challenge:challenges(id, title, description, type, scoring, start_date, end_date, status, prize_coins)')
    .eq('user_id', userId)
  Filter locally: challenge.status === 'active' AND new Date(challenge.end_date) > new Date()
  Progress: score / estimatedTarget; estimatedTarget derived from scoring type:
    'sessions': (days_total / 7) * 3  (default 3 sessions/week)
    'volume': 10000  (default 10 ton target)
    'habits': days_total  (one per day)
    else: 100 (fallback)
  days_total = differenceInDays(new Date(end_date), new Date(start_date)) from date-fns

challenges.status = 'active' JOIN query (alternative — fetch all active challenges):
  supabase.from('challenges')
    .select('*, challenge_participants!left(user_id, score, status)')
    .eq('status', 'active')
    .gt('end_date', new Date().toISOString())
    .limit(20)
  Then: isEnrolled = row.challenge_participants?.some(p => p.user_id === userId)

Friend color hash (UI-SPEC §6.3):

  CREATE POLICY "workout_sessions_friends_read" ON public.workout_sessions
