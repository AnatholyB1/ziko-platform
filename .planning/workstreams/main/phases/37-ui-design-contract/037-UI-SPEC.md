## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, AI chip gap |
| sm | 8px | Compact element spacing, chip padding |
| md | 16px | Default element spacing, card inner horizontal padding |
| lg | 24px | Card padding (`p-6`), section padding |
| xl | 32px | Dashboard page horizontal padding (`px-8`) |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Chart card AI insight row top margin: 12px (`mt-3`) — between rule and content
- Control bar bottom margin: 16px (`mb-4`) — between control bar and grid
- Grid gap: 16px (`gap-4`) — between chart cards in the 2×2 grid

```tsx
// dashboard/page.tsx (Client Component)
'use client';

export default function DashboardPage({ params }: { params: { id: string } }) {
  const [sport, setSport] = useState<SportType | null>(null);
  const [dateRange, setDateRange] = useState<'week' | 'month' | '3m'>('month');
  
  return (
    <div className="px-8 py-6">
      {/* Global Control Bar */}
      <DashboardControlBar sport={sport} onSportChange={setSport} dateRange={dateRange} onDateRangeChange={setDateRange} />

      {sport === null && <EmptyState message="Sélectionnez un sport pour afficher le dashboard." />}
      {sport === 'powerlifting' && <PowerliftingDashboard clientId={params.id} dateRange={dateRange} />}
      {/* ... other sports */}
    </div>
  );
}
```

## Motion Design

> Personality: Snappy + Fluid (from MOODBOARD.md) — web implementation uses CSS transitions and Tailwind animate utilities. NOT GSAP (web app, not mobile).

| Surface | Animation | Duration | Easing | Implementation |
|---------|-----------|----------|--------|----------------|
| Dashboard tab entrance | Fade + slide up | 200ms | ease-out | `opacity-0 translate-y-2 → opacity-100 translate-y-0` via CSS transition or Framer Motion `initial`/`animate` |
| Chart cards mount (4 cards) | Staggered fade-in | 200ms each, 50ms stagger | ease-out | Framer Motion `AnimatePresence` with `variants` — index × 50ms delay |
| Sport/date filter change | Charts cross-fade | 150ms | ease-out | Key prop change triggers re-mount with `AnimatePresence mode="wait"` |
| Loading skeleton | Pulse | 1.5s infinite | sine | Tailwind `animate-pulse` — no custom animation needed |
| Control bar | No animation | — | — | Instant — state controls are synchronous |
| Tab switch | Instant | — | — | Next.js Router handles navigation, no additional animation |
| Tooltip hover | Appear | 100ms | ease-out | Recharts built-in tooltip animation |
| Empty state appearance | Fade in | 200ms | ease-out | Single fade on initial render |
| Error state | Shake + border flash | 300ms | ease-in-out | CSS `@keyframes shake` or Framer Motion `x: [0, -6, 6, -4, 4, 0]` |

**Framer Motion setup (if used):**
```bash
npm install framer-motion
```

**Card stagger pattern (Framer Motion):**
```tsx
const containerVariants = {
  hidden: {},
  visible: {
    transition: { staggerChildren: 0.05 }
  }
};

const cardVariants = {
  hidden: { opacity: 0, y: 8 },
  visible: { opacity: 1, y: 0, transition: { duration: 0.2, ease: 'easeOut' } }
};

// Usage:
<motion.div variants={containerVariants} initial="hidden" animate="visible" className="grid grid-cols-2 gap-4">
  {cards.map((card, i) => (
    <motion.div key={i} variants={cardVariants}>
      <ChartCard {...card} />
    </motion.div>
  ))}
</motion.div>
```

**CSS-only alternative (if Framer Motion not used):**
```tsx
// Add to card className:
`opacity-0 animate-[fadeInUp_200ms_ease-out_forwards]`
// With inline style: animationDelay: `${index * 50}ms`

// In globals.css:

  from { opacity: 0; transform: translateY(8px); }
  to { opacity: 1; transform: translateY(0); }
}
```
