| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-038-07 | Elevation of Privilege | useQuery clientId | mitigate | clientId comes from URL params and is passed to fetchPowerliftingData which applies .eq('workout_sessions.user_id', clientId) + RLS is_coach_of() — two enforcement layers |
| T-038-08 | Information Disclosure | Recharts chart tooltip | accept | Recharts renders via React virtual DOM — exercise names and metric values auto-escaped; no raw HTML injection path |
| T-038-09 | Denial of Service | Large dataset (many sessions) | accept | Query is client-side only; Supabase returns at most the sessions in the date window (7/30/90 days); no pagination needed at this scale |
</threat_model>
