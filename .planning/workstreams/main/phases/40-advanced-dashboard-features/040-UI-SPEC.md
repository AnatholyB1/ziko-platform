**Value size in compare mode:** Drop from 28px to 22px (`text-[22px] font-bold`) to fit two values side-by-side in the card width (~370px at 2-col grid).

**DeltaChip component:**
```tsx
function DeltaChip({ delta, unit }: { delta: number; unit?: string }) {
  const isPositive = delta > 0;
  const isNeutral = delta === 0;
  return (
    <span className={`inline-flex items-center px-1.5 py-0.5 rounded text-xs font-medium ${
      isNeutral
        ? 'bg-[#F0EFE9] text-[#6B6963]'
        : isPositive
        ? 'bg-[#DCFCE7] text-[#15803D]'
        : 'bg-[#FEE2E2] text-[#B91C1C]'
    }`}>
      {isPositive ? '+' : ''}{delta}{unit ? ` ${unit}` : ''}
    </span>
  );
}
```
- Positive: green-100 bg, green-700 text
- Negative: red-100 bg, red-700 text
- Neutral: surface-muted bg, text-muted
- Padding: `px-1.5 py-0.5`
- Border radius: `rounded` (4px)

```tsx
function LegendDot({ color, label }: { color: string; label: string }) {

  );
```

#### 4b. Line / Area Charts — Compare Mode

**Modification:** Add a second `<Line>` or `<Area>` with `dataKey` pointing at the comparison dataset. Both series rendered on the same axes.

**Single-mode line (unchanged):**
```tsx

```

**Compare-mode lines:**
```tsx

<Line dataKey="valueA" stroke="#FF5C1A" strokeWidth={2} dot={false} connectNulls name={subjectALabel} />
{/* Series B — comparison subject */}
<Line dataKey="valueB" stroke="#3B82F6" strokeWidth={2} dot={false} strokeDasharray="5 3" connectNulls name={subjectBLabel} />
```

`strokeDasharray="5 3"` on Series B differentiates it visually from Series A without relying on color alone (accessibility consideration).

**Data merge strategy:** When compare mode is active, the data array is merged on the shared `date` key:
```ts
type CompareDataPoint = {
  date: string;
  valueA: number | null;    // current subject
  valueB: number | null;    // comparison subject
};
```

**Legend (always shown in compare mode):**
```tsx

```

**Area charts — compare mode:**
```tsx
{/* Series A */}
<Area dataKey="valueA" stroke="#FF5C1A" fill="#FF5C1A" fillOpacity={0.06} strokeWidth={2} dot={false} name={subjectALabel} />
```

## Motion Design

> Personality: Snappy + Fluid (from MOODBOARD.md) — web implementation uses CSS transitions. NOT GSAP. Platform: Next.js + Tailwind CSS.

All Phase 37 motion contracts remain in force. The following are Phase 40 additions.

| Surface | Animation | Duration | Easing | Implementation |
|---------|-----------|----------|--------|----------------|
| Sub-tab switch (Sport → Personnalisé) | Content cross-fade | 150ms | ease-out | `opacity-0 → opacity-100` on content swap; use `key` prop change on tab content wrapper to trigger re-mount |
| Sub-tab active pill | Background/color transition | 150ms | ease-out | `transition-colors` on both buttons — Tailwind handles the bg/text color interpolation |
| Compare row expand | Slide down from ControlBar | 300ms | ease-out | CSS `max-height: 0 → max-height: 80px` + `opacity: 0 → 1` — both on `transition-all duration-300 ease-out` |
| Compare row collapse | Slide up into ControlBar | 250ms | ease-in | CSS `max-height: 80px → 0` + `opacity: 1 → 0` — asymmetric: collapse slightly faster than expand |
| Compare mode enable — chart cards | Fade + overlay appear | 200ms | ease-out | Loading overlay: `opacity-0 → opacity-100` via `transition-opacity duration-200` |
| Compare data loaded — charts update | Series fade in | 250ms | ease-out | New series enters with `opacity: 0 → 1` — CSS or Recharts built-in transition |
| PDF button generating state | Spinner entrance | 150ms | ease-out | `transition-all` on button contents swap |
| PDF button done flash | Green state | 2000ms hold, 200ms fade | ease-out | `setTimeout(2000)` then transition back to idle |
| Compare exclude note card | Fade in | 200ms | ease-out | Same stagger pattern as chart cards from Phase 37 |
| Delta chip entrance (compare populated) | Scale in | 150ms | ease-out | `scale-0 → scale-100` via `transition-transform` or small Framer Motion `initial={{ scale: 0.7 }}` |

**Compare row expand — full CSS pattern:**
```tsx
// Wrapper div
<div
  className={`overflow-hidden transition-all ease-out ${
    compareMode
      ? 'max-h-20 opacity-100 duration-300'
      : 'max-h-0 opacity-0 duration-250'
  }`}
>
  {/* inner content always mounted — collapsed via max-height */}
  <div className="flex items-center gap-3 py-3 border-t border-border">
    {/* ... */}
  </div>
</div>
```

Note: `duration-250` is not a default Tailwind class — use inline `style={{ transitionDuration: '250ms' }}` or extend Tailwind config with `250` in `transitionDuration`.

**Sub-tab content transition (key-based re-mount):**
```tsx
<div key={activeTab} className="opacity-0 animate-[fadeIn_150ms_ease-out_forwards]">
  {activeTab === 'sport' ? <SportDashboardContent /> : <PersonnaliseDashboardContent />}
</div>
```
Where `fadeIn` is already defined in Phase 37's `globals.css`:
```css
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}
```
(If Phase 37 only defined `fadeInUp`, add a plain `fadeIn` variant to globals.css.)

| **html2canvas** | PDF export — DOM-to-canvas capture | **NEW — must install** `npm install html2canvas` | No third-party registry — npm package. Review: captures DOM bitmap, no network calls, client-side only. No flags. |
| **jsPDF** | PDF export — canvas-to-PDF conversion | **NEW — must install** `npm install jspdf` | No third-party registry — npm package. Review: converts canvas/image data to PDF, no network calls, client-side only. No flags. |

**html2canvas + jsPDF integration notes:**
- Both are client-side only — import must be guarded with `typeof window !== 'undefined'` or dynamic import `import('html2canvas')` / `import('jspdf')` to avoid SSR errors in Next.js
- Use dynamic import pattern:
  ```ts
  const html2canvas = (await import('html2canvas')).default;
  const { jsPDF } = await import('jspdf');
  ```
- The export button's `onClick` handler captures a `ref` attached to the dashboard content container
- Exclude control buttons from capture by passing `ignoreElements: (el) => el.classList.contains('pdf-exclude')` to `html2canvas`
- Add `pdf-exclude` class to: DashboardControlBar, sub-tab strip, Éditer button

No third-party registries declared. No vetting gate required.
