## Component Inventory

Four new components in this phase. All use existing patterns — no new design patterns introduced.

### 1. DashboardChatDrawer

- **Surface:** Fixed right-side panel, 420px wide, full viewport height, white background (#FFFFFF), 1px left border (border-border), z-index above dashboard content
- **Backdrop:** Semi-transparent overlay on the dashboard area behind the drawer — `bg-black/20` (20% opacity), not full-screen block
- **Animation:** CSS `translate-x-full` → `translate-x-0` transition, 200ms ease-out. Mirrors DashboardEditOverlay GSAP entrance pattern in spirit; implementation uses CSS transition (no GSAP dependency for a simpler slide)
- **Header:** 56px tall, white bg, bottom border (border-border). Left: "IA Coach" title (text-xl font-bold text-text). Right: X close button (lucide `X`, 20px, text-muted, hover:text-text)
- **Message area:** Scrollable, bg-background (#F7F6F3), no card wrapping individual messages — same pattern as existing AI chat
- **Input bar:** Fixed bottom of drawer panel, white bg, top border. Textarea (bg-background, border-border, grows to max-h-[120px], rounded-xl), Send button (bg-primary, rounded-lg, 10px radius)
- **Streaming cursor:** Blinking `|` in Sprint Orange (#FF5C1A) after last streamed character
- **Error state:** `bg-red-50 border border-red-200 rounded-lg` inline. "Réessayer" in text-primary. Not a modal.

### 2. NarrativeSummaryCard

- **Position:** Full-width, above the 2×2 chart grid, below DashboardControlBar
- **Anatomy:** Same as ChartCard: `bg-white rounded-2xl border border-border p-6` — no nested card
- **Header row:** Left: `🧠` emoji (1rem) + sport name (text-sm font-semibold text-text). Right: nothing (no actions)
- **Body:** One paragraph of AI-generated text (text-sm/400/1.6, text-text, max 65ch line length enforced via `max-w-prose`)
- **Loading state:** Two skeleton lines — `bg-[#E2E0DA] rounded animate-pulse`, heights 12px and 8px, widths 90% and 70%
- **Error/no-sport state:** Not rendered (component returns null when sport is null or insights fetch errored — silent fail per D-09 pattern)

### 3. DashboardChatDrawer trigger button ("Demander à l'IA") in DashboardControlBar

- **Label:** "Demander à l'IA"
- **Icon:** lucide `MessageCircle` (w-4 h-4), left of label
- **Variant:** Primary (bg-primary text-white font-bold, h-9 px-3, rounded-lg) — this is the primary CTA for the phase
- **Active/open state:** `opacity-90` (drawer is open, button not toggled off — button remains visible but drawer has own close)
- **Placement:** Rightmost button in ControlBar right section, after "Exporter PDF"

### 4. AlertesModal (threshold configuration panel)

- **Trigger button:** "Alertes" in ControlBar right section (between "Comparer" and date filter, or after "Demander à l'IA" — see note)
  - Variant: Ghost (border border-border bg-white, h-9 px-3, rounded-lg, text-sm font-medium text-text)
  - Icon: lucide `Bell` (w-4 h-4 text-muted left of label)
  - Badge: Sprint Orange dot (8px, bg-primary, rounded-full) top-right of button when ≥1 threshold currently crossed
- **Modal overlay:** `fixed inset-0 bg-black/40 z-50 flex items-center justify-center`
- **Panel:** `bg-white rounded-2xl border border-border p-6 w-[480px] max-h-[80vh] overflow-y-auto shadow-lg`
- **Panel header:** "Alertes seuils" (text-xl font-bold text-text) + X button (lucide X, text-muted)
- **Threshold row:** metric label (text-sm text-text) + operator chip (`>` / `<`, text-xs font-bold) + value input (h-9, w-20, border-border, rounded-lg, text-sm text-center) + delete button (lucide Trash2, text-muted hover:text-red-400)
- **Crossed threshold indicator:** Sprint Orange dot (8px) left of metric label when crossed
- **Add threshold:** "+ Ajouter un seuil" text button (text-primary text-sm font-bold, bottom of list)
- **Save button:** Primary (bg-primary text-white font-bold, full-width bottom of modal, h-11 rounded-xl)

### 5. ChartCard alert badge (extension of existing component)

- **Badge shape:** Pill — `text-xs font-bold px-2 py-0.5 rounded-full`
- **Warning color (delta ≤ 20%):** `bg-[#FFF7ED] text-[#FF5C1A] border border-[#FF5C1A]/20` — Sprint Orange tint
- **Critical color (delta > 20%):** `bg-red-50 text-red-500 border border-red-200` — Alert Red tint
- **Position:** Inline in ChartCard title bar, right-aligned after the title text
- **Content:** Compact: e.g. `RPE > 8.5` (metric key + operator + threshold value — no current value in badge, detail in modal)

### 6. AI Insight chip (existing aiInsight slot in ChartCard)

- **Loading state:** Replace insight text with "Analyse en cours…" in text-muted italic — no separate skeleton component needed; the existing footer div already renders at fixed height
- **Real content:** text-xs text-muted (existing), max 80 characters enforced in prompt response
- **Error/silent fallback:** Empty string passed → existing `?? 'Analyse IA disponible en phase 41'` fallback fires — no error UI needed

## Interaction States

### DashboardChatDrawer

| State | Visual |
|-------|--------|
| Closed | Not rendered (or translate-x-full off-screen) |
| Opening | CSS slide-in, 200ms ease-out, backdrop fades in simultaneously |
| Open / idle | Full panel visible, input bar focused |
| Streaming | TypingIndicator shows until first chunk, then streaming bubble with blinking `|` |
| Error | Inline error banner inside message area (red-50, border-red-200) |
| Closing | translate-x-full, 150ms ease-in, backdrop fades out |

### NarrativeSummaryCard

| State | Visual |
|-------|--------|
| No sport selected | Card not rendered |
| Insights loading | 2-line skeleton (animate-pulse, rounded, bg-[#E2E0DA]) |
| Loaded | Narrative paragraph, max-w-prose |
| Error | Card not rendered (silent fail) |

### ChartCard with insight + alert badge

| State | Visual |
|-------|--------|
| No insights loaded | Existing placeholder "Analyse IA disponible en phase 41" |
| Insights loading | "Analyse en cours…" in text-muted italic |
| Insight loaded | Real one-liner text, text-xs text-muted |
| Threshold not crossed | No badge |
| Threshold crossed (warning) | Orange tint pill badge in title bar |
| Threshold crossed (critical) | Red tint pill badge in title bar |

### AlertesModal

| State | Visual |
|-------|--------|
| Closed | Not rendered |
| Open, no thresholds | Empty state (no icon, just text heading + body copy + add button) |
| Open, thresholds exist | Rows list, each row with metric/operator/value/delete |

| Save success | Modal closes, toast "Seuils enregistrés" (1.5s) |

## Layout Constraints

- **Dashboard page layout is unchanged**: ControlBar → NarrativeSummaryCard (new, full-width) → chart grid (2×2)
- **Drawer does not reflow the page**: It overlays from the right with a backdrop. Charts remain visible (partially) behind the backdrop.
- **ControlBar button order** (right section, left to right): Comparer | date segmented control | "Alertes" ghost button | "Demander à l'IA" primary button | "Exporter PDF" ghost button
  - Rationale: AI actions grouped on the far right, with the primary CTA ("Demander à l'IA") as the last button before the consistently-placed PDF export.
- **Drawer width**: 420px on desktop (lg+). On md and below: full viewport width minus 16px side padding.
- **Modal width**: 480px fixed, centered. On sm: full-width with mx-4.

## Animation Contract

| Element | Animation | Duration | Easing |

| DashboardChatDrawer close | translateX: 0 → 100% | 150ms | ease-in |

No layout property (`height`, `margin`, `padding`) animations. All transitions use `transform` and `opacity`. Source: DESIGN.md "Don't animate CSS layout properties."
