## Completed Requirements

### A — Foundation (DB + Backend)

- [x] **FOUND-01** — Coach peut sauvegarder sa DA (couleur primaire hex, logo URL, ton) dans `coach_branding`
  - **Outcome:** Migration 054 + `PATCH /coach/branding` upsert — validated
- [x] **FOUND-02** — Un athlète lié peut lire la DA de son coach via `GET /coach/clients/links/me`
  - **Outcome:** `getActiveLink()` augmented to return `branding: BrandingRow | null` — validated
- [x] **FOUND-03** — La DA est réservée au tier Pro (gate backend + web)
  - **Outcome:** Service-key tier check before upsert (403 for non-Pro) + `isPro` prop in web editor — validated
- [x] **FOUND-04** — RLS : seul le coach owne son enregistrement ; ses athlètes liés peuvent le lire
  - **Outcome:** Dual RLS policy: `coach_id = auth.uid()` (coach) + `is_coach_of(coach_id, auth.uid())` (athlete) — validated

### B — Web Editor (coach)

- [x] **WEB-01** — Coach peut sélectionner une couleur primaire via color picker (hex, avec preview swatch)
  - **Outcome:** ColorPickerInput with hex validation + live swatch + 5 presets — validated
- [x] **WEB-02** — Coach peut uploader son logo (PNG/SVG ≤ 2MB) dans le bucket `coach-logos`
  - **Outcome:** LogoUpload with direct Supabase Storage upload (upsert=true) — validated
- [x] **WEB-03** — Coach voit un preview live de sa DA (card athlète simulée) avant de sauvegarder
  - **Outcome:** BrandingPreviewCard purely prop-driven, updates in real-time — validated
- [x] **WEB-04** — Coach choisit son ton parmi 4 options (Motivant / Analytique / Bienveillant / Exigeant)
  - **Outcome:** ToneSelector ARIA radiogroup (4 pills) — validated
- [x] **WEB-05** — Un coach non-Pro voit l'éditeur verrouillé avec preview + CTA upgrade
  - **Outcome:** `isPro=false` swaps Save for "Passer en Pro" CTA; all controls remain interactive — validated

### C — Mobile Injection (athlète)

- [x] **MOB-01** — L'app athlète applique la couleur primaire coach au refresh (State C du plugin Mon coach)
  - **Outcome:** `useBrandingBootstrap` hook calls `setCustomTheme({ primary })` on auth layout mount — validated
- [x] **MOB-02** — Le logo coach s'affiche dans la card "Mon coach" (State B et C)
  - **Outcome:** `CoachAvatar` updated to accept `logoUrl` prop; constructs public URL via Supabase Storage — validated
- [x] **MOB-03** — La DA persiste au redémarrage via MMKV (pas de flash orange au cold start)
  - **Outcome:** MMKV synchronous read in `useThemeStore` `create()` initializer — cold-start guarantee — validated
- [x] **MOB-04** — La révocation du lien coach remet le thème Ziko par défaut (`clearCoachTheme`)
  - **Outcome:** `clearCoachTheme()` + `coachStorage.delete('coach:branding')` in `handleRevoke` — validated
