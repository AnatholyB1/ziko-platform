## Milestone Summary

**Key Decisions:**

- `coach_branding` table separate from `coach_profiles` (different lifecycle/change rate)
- `logo_url` stores bucket path (not full URL) — avoids URL coupling to Supabase project domain
- `coach-logos` bucket is `public=true` — logo images are non-sensitive public branding assets
- Theme injection via `setCustomTheme()` with inline style objects only — no NativeWind class interpolation
- RLS uses `is_coach_of(coach_id, auth.uid())` — coach_id first, client second (matches migration 035)
- MMKV required for cold-start guarantee — synchronous read inside Zustand `create()` before first render
- `tabBarActive` and `primaryLight` auto-derived from `primary` in `setCustomTheme` — cannot be spoofed by caller
- `clearCoachTheme` delegates to `get().resetTheme()` — single reset path
- `isPro` gate computed server-side in Next.js page.tsx — client receives read-only boolean prop
- Dedicated MMKV instance (`coach-storage`) for branding namespace isolation
- `queryKey: ['coach-link', userId]` shared between `useBrandingBootstrap` and `CoachScreen` — TanStack deduplication
- `coachStorage` imported from `@ziko/plugin-sdk` in CoachScreen (not relative path) — re-exported via `export * from './theme'`

**Technical Debt Incurred:**

- Tone injection into Claude system prompt deferred to post-v1.12 (needs additional backend hook)
- `user_profiles.id` vs `user_profiles.user_id` inconsistency between `creditGate.ts` (uses `user_id`) and branding Pro gate (correctly uses `id`) — pre-existing, noted in 01-03-SUMMARY

**Issues Resolved:**

- npm `--legacy-peer-deps` required for `react-native-mmkv@3.3.3` — false conflict with `^0.81.5` workspace constraint (0.81.5 satisfies `*`)
- GSAP TypeScript error: `x: number[]` not assignable to `TweenValue` — fixed with `fromTo + keyframes` syntax throughout

**EAS Build Required:**
A new EAS build (iOS and/or Android) is required for `react-native-mmkv` JSI native module to work on device.
