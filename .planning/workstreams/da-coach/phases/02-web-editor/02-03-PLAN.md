    Imports: useState, useEffect, useRef from 'react'; gsap from 'gsap'; createClientSupabase from '@/lib/supabase/client'; ColorPickerInput from '@/components/coach/ColorPickerInput'; LogoUpload from '@/components/coach/LogoUpload'; ToneSelector from '@/components/coach/ToneSelector'; BrandingPreviewCard from '@/components/coach/BrandingPreviewCard'; IoSparklesOutline, IoCheckmarkCircle from 'react-icons/io5'.

    Const API_URL = process.env.NEXT_PUBLIC_API_URL ?? 'http://localhost:3000'.

    Props interface BrandingClientProps:
    - userId: string
    - isPro: boolean
    - displayName: string
    - initialBranding: { primary_color: string; logo_url: string | null; tone: string | null } | null

    State:
    - primaryColor: string — initialized from initialBranding?.primary_color ?? ''
    - logoPath: string | null — initialized from initialBranding?.logo_url ?? null
    - tone: string | null — initialized from initialBranding?.tone ?? null
    - jwt: string | null — initialized null
    - saving: boolean — initialized false
    - toast: { type: 'success' | 'error'; message: string } | null — initialized null
    - toastVisible: boolean — initialized false

    JWT fetch in useEffect (empty deps):
    createClientSupabase().auth.getSession().then(result => setJwt(result.data.session?.access_token ?? null))

    GSAP page entrance in useEffect (empty deps, runs after JWT fetch):
    gsap.from('.branding-section', { y: 20, opacity: 0, duration: 0.25, ease: 'power2.out', stagger: 0.06, delay: 0.05 })
    gsap.from('.preview-card', { y: 16, opacity: 0, duration: 0.3, ease: 'power2.out', delay: 0.2 })

    Toast useEffect: when toastVisible is true, schedule auto-dismiss:
    const timer = setTimeout(() => { gsap.to('.success-toast, .error-toast', { y: 10, opacity: 0, duration: 0.2, ease: 'power2.in', onComplete: () => { setToastVisible(false); setToast(null); } }); }, 3000). Return () => clearTimeout(timer).

    Show toast helper (showToast(type, message)):
    setToast({ type, message }); setToastVisible(true).
    Then fire GSAP entrance: gsap.from('.success-toast, .error-toast', { y: 20, opacity: 0, duration: 0.25, ease: 'power2.out' }).

    handleSave async function:
    1. If saving return.
    2. Fire GSAP on save button: gsap.to('.save-btn', { scale: 0.97, duration: 0.1, yoyo: true, repeat: 1, ease: 'power3.out' }).
    3. setSaving(true).
    4. Try: const res = await fetch(`${API_URL}/coach/branding`, { method: 'PATCH', headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${jwt}` }, body: JSON.stringify({ primary_color: primaryColor || undefined, logo_url: logoPath, tone }) }).
    5. If (!res.ok): throw new Error('save_failed').
    6. showToast('success', 'Direction artistique enregistrée.').
    7. Catch: showToast('error', 'Erreur lors de l\'enregistrement. Réessayez.'). Fire error shake: gsap.to('.save-btn', { x: [-4, 4, -3, 3, 0], duration: 0.3, ease: 'none' }).
    8. Finally: setSaving(false).

    Render structure (no loading gate on jwt — page still renders, Save is disabled when jwt is null):

    Wrapper fragment (<>).

    Grid section: div className "grid lg:grid-cols-2 gap-8".

    Left column: div className "flex flex-col gap-6".
    Contains in order:
    1. ColorPickerInput value={primaryColor} onChange={setPrimaryColor}
    2. LogoUpload userId={userId} currentPath={logoPath} onUploaded={(path) => setLogoPath(path)} onRemoved={() => setLogoPath(null)}
    3. ToneSelector value={tone} onChange={setTone}
    4. Action row: div className "flex justify-end pt-2".
       When isPro: button type="button" onClick={handleSave} disabled={saving || !jwt} aria-busy={saving} className="save-btn h-11 px-6 bg-primary text-white rounded-xl text-sm font-bold hover:bg-primary/90 transition-colors disabled:opacity-50 disabled:cursor-not-allowed". Copy: saving ? 'Enregistrement…' : 'Enregistrer'.
       When !isPro: div className "flex items-center gap-4". p className "text-sm text-muted" text "Passez en Pro pour sauvegarder votre direction artistique." button type="button" className "h-11 px-6 bg-primary text-white rounded-xl text-sm font-bold hover:bg-primary/90 transition-colors inline-flex items-center gap-2" onClick={() => window.location.href = '/coach/settings?tab=subscription'}. Icon IoSparklesOutline size={16}. Copy "Passer en Pro".

    Right column: div className "lg:sticky lg:top-10".
    Contains: BrandingPreviewCard primaryColor={primaryColor} logoPath={logoPath} displayName={displayName} tone={tone}

    When toastVisible and toast is non-null:

    Inside: IoCheckmarkCircle size={20} className={toast.type === 'success' ? 'text-green-500' : 'text-red-500'}. span className "text-sm font-normal text-text" with toast.message.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser→Hono API | PATCH /coach/branding with JWT Bearer — backend validates JWT + Pro tier |
| client state→server | isPro from server prop; client cannot elevate — Save button removal is cosmetic; the 403 from backend is the real gate |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Elevation of Privilege | isPro client gate | mitigate | UI button swap is cosmetic only. Backend PATCH /coach/branding returns 403 for non-Pro coaches (Phase 1 guard). If a non-Pro user removes the UI gate via DevTools and calls PATCH, the backend 403 blocks the save. |
| T-02-07 | Spoofing | JWT in handleSave | mitigate | JWT obtained from Supabase auth.getSession() — cannot be forged client-side. Backend validates JWT via auth middleware before processing PATCH. |
| T-02-08 | Tampering | primary_color sent to PATCH | mitigate | Backend validates hex format via CHECK constraint (^#[0-9A-Fa-f]{6}$ from Phase 1 D-04). Client-side validation (in ColorPickerInput) is UX only, not the security gate. |
| T-02-09 | Information Disclosure | toast message on PATCH failure | accept | Generic error message shown — no server error details leaked to user. |
| T-02-SC | Tampering | npm installs | accept | No new npm packages — gsap, react-icons/io5, and @supabase/supabase-js are already installed |
</threat_model>
