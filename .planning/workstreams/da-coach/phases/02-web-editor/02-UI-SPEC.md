# UI-SPEC: Phase DA-02 — Web Editor (Direction Artistique)

> Visual and interaction contract for the `/coach/branding` page in the Next.js CRM.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

## Overview

A Pro coach configures their Direction Artistique (primary color, logo, tone de coaching) from the web CRM and sees a live preview card mimicking what athletes will see. Non-Pro coaches see all controls but the Save button is replaced by a Pro upgrade CTA. The page is a new standalone route `/coach/branding`, not a section inside settings.

**Platform:** Web (Next.js CRM — `apps/web`) — 1440px desktop canvas. Responsive down to 768px (sidebar collapses). This is NOT a mobile design.

## Section Specs

### ColorPickerSection

**Card:** `bg-white rounded-2xl p-8 border border-border shadow-sm`

**H2:** `text-base font-bold text-text mb-5`
Copy: "Couleur principale"

**Helper text below H2:** `text-xs text-muted mb-5`
Copy: "Cette couleur sera appliquée comme accent dans l'app de vos athlètes."

**Layout:** `flex items-center gap-3`

**Swatch component:**
- Size: `w-10 h-10 rounded-lg border border-border flex-shrink-0`
- Valid state: `background: {inputtedHex}; border-color: {inputtedHex};` with `ring-2 ring-offset-1 ring-primary`
- Invalid/empty state: `background: #F0EFE9; border-color: #E2E0DA;` — no ring
- Transition: `transition-colors duration-150`

**Hex input:**
- `h-11 w-36 px-3 bg-white border border-border rounded-xl text-sm font-normal text-text placeholder:text-muted font-mono`
- Placeholder: `#FF5C1A`
- Validation feedback: no border change on invalid — swatch remains neutral. No error text on partial input.
- On valid (matches `^#[0-9A-Fa-f]{6}$`): swatch activates. Input border remains unchanged.

**Quick presets row (below input):**
- `flex gap-2 mt-3`
- 5 preset dots: each `w-6 h-6 rounded-full cursor-pointer border-2 border-transparent hover:border-border transition-colors`
- Preset hex values: `#FF5C1A` (Ziko orange), `#3B82F6` (blue), `#8B5CF6` (purple), `#22C55E` (green), `#1C1A17` (black)
- Clicking a preset fills the hex input and activates the swatch
- Helper text below presets: `text-xs text-muted mt-1` — "Ou entrez un code hex personnalisé"

**States:**

*Empty (no color saved):*
- Input empty, placeholder visible, swatch neutral grey `#F0EFE9`

*Valid hex entered:*
- Input shows e.g. "#3B82F6", swatch fills with that color + ring-primary

*Invalid partial input (e.g. "#3B8"):*
- Input shows partial text, swatch remains neutral — no error shown, no border change

## Motion Design

**Personality:** Snappy + Fluid hybrid — from MOODBOARD.md
**Entrances:** 200ms `power2.out`. Exits: 150ms `power2.in`. Interactive: 100ms `power3.out`.

**GSAP is loaded in the web CRM. All contracts below use GSAP v3 syntax.**

### Screen: BrandingPage — Page Entrance

```js
// Page mount: stagger cards in from below
gsap.from(".branding-section", {
  y: 20,
  opacity: 0,
  duration: 0.25,
  ease: "power2.out",
  stagger: 0.06,
  delay: 0.05,
});

// Right column preview card entrance
gsap.from(".preview-card", {
  y: 16,
  opacity: 0,
  duration: 0.3,
  ease: "power2.out",
  delay: 0.2,
});
```

### Component: ColorPickerSection — Swatch Activation

```js
// When hex input transitions from invalid → valid
gsap.fromTo(".color-swatch", 
  { scale: 0.85, opacity: 0.5 },
  { scale: 1, opacity: 1, duration: 0.2, ease: "back.out(1.4)" }
);
```

  scale: 0.85,

### Note on Color Transition in PreviewCard

The accent bar and tone badge background use CSS `transition: background-color 150ms ease` — GSAP is not needed for continuous live-preview color updates. GSAP is reserved for structural changes (element appear/disappear/shake). This keeps the color picker feeling instant and responsive without GSAP overhead on every keystroke.

## API Integration

**PATCH /coach/branding** (Phase 1 endpoint)
- Method: `PATCH`
- URL: `${NEXT_PUBLIC_API_URL}/coach/branding`
- Headers: `{ Authorization: Bearer ${jwt}, Content-Type: application/json }`
- Body: `{ primary_color: "#3B82F6", logo_url: "userId/logo.png", tone: "motivant" }`
- All fields optional — send only what has changed (or send all)
- 403 on non-Pro coach (backend guard from Phase 1)
- 200 on success

**Logo URL stored in DB:** bucket path only, e.g. `550e8400.../logo.png`
**Logo URL for preview:** `supabase.storage.from('coach-logos').getPublicUrl(path).data.publicUrl`

## Accessibility

- Color hex input: `aria-label="Code couleur hexadécimal"`, `aria-describedby="hex-helper"`
- Swatch: `aria-hidden="true"` (decorative)
- Logo input: `aria-label="Choisir un logo (PNG ou SVG, max 2 Mo)"`
- Tone pills: `role="radio"` on each, `role="radiogroup"` on container, `aria-checked={isActive}`
- Save button: `aria-busy={saving}` during saving state
- Toast: `role="status" aria-live="polite"`
- All interactive elements: min touch target 44×44px (web equivalent via min-height/padding)
