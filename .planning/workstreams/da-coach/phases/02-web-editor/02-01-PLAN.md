       - supabase.from('coach_profiles').select('display_name').eq('user_id', user.id).single() — stores result as profileData
    4. Derive: const isPro = tierData.data?.tier === 'premium' (boolean, defaults to false on null/error).
    5. Derive: const initialBranding = brandingData.data ?? null (type: { primary_color: string; logo_url: string | null; tone: string | null } | null).
    6. Derive: const displayName = profileData.data?.display_name ?? 'Votre nom'.

    Render a wrapper div with className "px-8 py-10 max-w-[1200px] mx-auto flex flex-col gap-8".

    Inside it render:
    - A header div containing: h1 with className "text-2xl font-bold text-text" and text "Direction artistique", then p with className "text-sm text-muted mt-1" and text "Personnalisez votre identité visuelle. Vos athlètes verront ces couleurs et ce logo dans leur app."
    - BrandingClient component (imported from './BrandingClient') with props: userId={user.id} isPro={isPro} initialBranding={initialBranding} displayName={displayName}

    BrandingClient does not exist yet (created in Plan 03) — use a type-safe forward declaration or a temporary stub import comment. The file can compile once BrandingClient.tsx exists.
