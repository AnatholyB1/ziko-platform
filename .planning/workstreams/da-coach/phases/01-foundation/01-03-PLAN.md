<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → PATCH /coach/branding | Untrusted JSON body; caller JWT determines identity |
| PATCH handler → user_profiles | Service-key read for tier check — cannot be spoofed by the caller's JWT |
| PATCH handler → coach_branding upsert | User-scoped JWT ensures RLS enforces coach_id = auth.uid() |
| GET /links/me → coach_branding SELECT | User-scoped JWT; athlete reads via is_coach_of() RLS policy |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Elevation of Privilege | PATCH /coach/branding Pro gate | mitigate | Tier check runs BEFORE any DB write; uses service-key client (not caller JWT) to read user_profiles.tier so caller cannot manipulate their own tier via JWT |
| T-03-02 | Tampering | PATCH body primary_color | mitigate | Server-side regex `/^#[0-9A-Fa-f]{6}$/` validation before upsert; invalid value returns 400 — DB CHECK is a second layer |
| T-03-03 | Tampering | PATCH body tone | mitigate | Allowlist check in handler before upsert; invalid value returns 400 — DB CHECK is a second layer |
| T-03-04 | Tampering | upsertBranding coachId | mitigate | `coach_id` in upsert comes from `c.get('auth').userId` (set by authMiddleware from JWT) — not from request body; caller cannot set coach_id to another user's ID |
| T-03-05 | Information Disclosure | getActiveLink branding field | accept | branding data (hex color, logo path, tone) is non-sensitive branding configuration; RLS ensures athletes only see their own linked coach's branding |
| T-03-SC | Tampering | npm install in this plan | accept | No new packages installed; only existing @supabase/supabase-js and hono dependencies used |
</threat_model>
