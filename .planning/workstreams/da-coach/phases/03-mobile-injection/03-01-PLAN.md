  <action>
    Edit `packages/plugin-sdk/src/theme.ts`:

    1. Add import at the top of the file:
       ```ts
       import { MMKV } from 'react-native-mmkv';
       ```

    2. Create a module-level MMKV instance (Claude's discretion: dedicated or shared — use dedicated for clarity):
       ```ts
       const coachStorage = new MMKV({ id: 'coach-storage' });
       ```

    3. In the `create<ThemeState>()((set, get) => ({ ... }))` block, replace the hardcoded initial `theme: DEFAULT_THEME` with a synchronous MMKV read:

       At the TOP of the create() callback (before the action methods), add a helper that computes the initial theme:
       ```ts
       const initialTheme = (() => {
         try {
           const raw = coachStorage.getString('coach:branding');
           if (!raw) return DEFAULT_THEME;
           const branding = JSON.parse(raw) as { primary_color?: string };
           if (!branding?.primary_color) return DEFAULT_THEME;
           const primary = branding.primary_color;
           return {
             ...DEFAULT_THEME,
             primary,
             primaryLight: primary + '15',
             tabBarActive: primary,
           };
         } catch {
           return DEFAULT_THEME;
         }
       })();
       ```

       Then use `initialTheme` as the initial value: `theme: initialTheme`.

    4. Export `coachStorage` from the module so Plans 03-02 and 03-03 can import it for write/delete operations:
       ```ts
       export { coachStorage };
       ```

    Do NOT modify the existing `setCustomTheme`, `clearCoachTheme`, `resetTheme`, `setTheme`, `setBanner` actions.
    Do NOT modify `ThemePalette`, `DEFAULT_THEME`, `THEME_REGISTRY`, `BANNER_REGISTRY`.
  </action>
