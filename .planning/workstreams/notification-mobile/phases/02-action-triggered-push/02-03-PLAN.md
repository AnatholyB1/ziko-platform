<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Supabase → POST /push-events/supabase | Supabase DB webhook crosses from external caller into Hono — must be authenticated |
| push-events handler → notificationService | Internal send triggered by a DB event, not a user action — no JWT context |
| notificationService → Expo Push API | Backend sends to athlete device on session-end and level-up events |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03-01 | Spoofing | POST /push-events/supabase | mitigate | X-Webhook-Secret header guard: any request without process.env.WEBHOOK_SECRET returns 401. Supabase sends the secret on every webhook POST. |
| T-02-03-02 | Tampering | Webhook payload | mitigate | Handler reads only record.user_id, record.id, record.ended_at, record.level, old_record.level from the payload — all used as filter inputs, not trusted for DB writes. The notificationService.send() call itself validates recipient tokens via the admin client. |
| T-02-03-03 | Repudiation | PUSH-03 duplicate suppression | mitigate | idempotencyKey session_summary_{userId}_{sessionId} ensures notification_log UNIQUE constraint prevents double-sends if Supabase retries the webhook. |
| T-02-03-04 | Repudiation | PUSH-04 level-up collapse | mitigate | idempotencyKey levelup_{userId}_{newLevel} means multiple XP events at the same level produce one push. ON CONFLICT DO NOTHING in notification_log handles the rest. |
| T-02-03-05 | Denial of Service | setTimeout(120_000) per session end | accept | One background async per session-end event. Vercel Pro: 300s max. 120s delay + send time well within budget. No amplification possible — one session end = one timeout. |
| T-02-03-06 | Information Disclosure | user_xp webhook payload | accept | Payload contains user_id and level — not PII beyond what the user already sees in the app. Level number is used only to construct the push body sent to that same user. |
| T-02-03-SC | Tampering | @vercel/functions (if new install) | mitigate | @vercel/functions is the official Vercel runtime package — verify on npmjs.com/package/@vercel/functions if not already in package.json. |
</threat_model>
