<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| expo-updates → Updates.reloadAsync() | OTA bundle comes from Expo's CDN, signed by Expo; no user-supplied code execution |
| isUpdateAvailable boolean → card render | No user input; read-only value from expo-updates hook |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-08 | Spoofing | OTA card trigger | accept | isUpdateAvailable can only be true if expo-updates detects a signed update from the configured EAS project — cannot be spoofed by external input |
| T-06-09 | Denial of Service | Updates.reloadAsync() called on tap | accept | reloadAsync() is idempotent (restarts app); user explicitly taps the CTA — no background auto-reload |
| T-06-10 | Information Disclosure | debugShowOTA flag | mitigate | debugShowOTA is `__DEV__ && false` — in production builds __DEV__ is always false so the flag can never expose the card in production even if the false is accidentally flipped |
</threat_model>
