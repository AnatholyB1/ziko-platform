<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Modal input → Supabase insert | reminder_time comes from a constrained InlinePicker (not free text); range is always "HH:00" for H in 6..23. No SQL injection vector. |
| habits data → scheduleNotificationAsync | Habit fields come from Supabase with RLS (auth.uid() = user_id); no cross-user data possible |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03 | Tampering | reminder_time value | mitigate | InlinePicker constrains input to predefined items (6h00–23h00); never free-text. scheduleHabitReminder parses with split(':').map(Number) — an invalid value produces NaN and the scheduling call silently no-ops. |
| T-06-04 | Denial of Service | schedulAllReminders on every habits refetch | accept | schedulAllReminders calls scheduleHabitReminder which internally calls cancelHabitReminder first — idempotent. Over-scheduling is harmless given typical habit counts (< 30). |
</threat_model>
