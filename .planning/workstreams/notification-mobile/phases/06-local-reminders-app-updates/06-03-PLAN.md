## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Weekday chip selection → scheduleNotificationAsync | Input constrained to predefined WEEKDAY_ORDER strings; DAY_TO_EXPO_WEEKDAY lookup returns undefined for unknown keys (no scheduling attempted) |
| notification_preferences UPSERT | Supabase RLS (notification_preferences_own: auth.uid() = user_id) prevents writing to other users' prefs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-05 | Tampering | workout_reminder_days JSONB input | mitigate | Array built from WEEKDAY_ORDER set membership toggle — only valid lowercase day strings can enter the array |
| T-06-06 | Tampering | Expo weekday off-by-one | mitigate | DAY_TO_EXPO_WEEKDAY explicit mapping dict with sunday:1 ensures correct weekday values — no arithmetic derivation |
| T-06-07 | Denial of Service | WEEKLY reminders accumulating across sessions | mitigate | cancelWorkoutReminders() (cancel by data.workoutReminder=true) runs before every reschedule — old triggers never accumulate |
| T-06-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this plan — expo-notifications and expo-updates already present |
</threat_model>
