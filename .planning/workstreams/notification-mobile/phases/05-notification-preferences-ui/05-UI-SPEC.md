- Coach: `#FF5C1A` (primary accent — coaching identity)

Shadow pattern for cards: `shadowColor: '#1C1A17', shadowOffset: { width: 0, height: 4 }, shadowOpacity: 0.08, shadowRadius: 8, elevation: 3`. Source: reference mockup + settings.tsx line 288-289.

## Screen Layout Contract

### NotifSubScreen structure (top to bottom)

```
SafeAreaView (flex: 1, backgroundColor: theme.background)
  STHeader (onBack, title="Notifications")
  ScrollView (padding: 16, paddingTop: 4, paddingBottom: 40)
    [Conditional] OS Settings denied CTA card     ← only if push permission denied
    STGroup (no title)
      STRow — "Toutes les notifications"  [master switch — push_enabled]
    STGroup (title="Catégories")
      STRow — "Coach"                     [coach_enabled, opacity 0.4 if master OFF]
      STRow — "Workout"                   [workout_enabled, opacity 0.4 if master OFF]
      STRow — "Gamification"              [gamification_enabled, opacity 0.4 if master OFF]
      STRow — "Santé & Habitudes"         [health_enabled, opacity 0.4 if master OFF]
      STRow — "App"                       [system_enabled, opacity 0.4 if master OFF]
    [Conditional] STGroup (title="Heures silencieuses")  ← only if push_enabled = true
      STRow — "De"    right=[picker trigger "22h00"]
      STRow — "À"     right=[picker trigger "7h00"]
  InlinePicker (quiet_hours_start)   ← bottom sheet modal
  InlinePicker (quiet_hours_end)     ← bottom sheet modal
```

### Loading state

When `isLoading = true` (prefs row not yet fetched):
- Show `STHeader` + centered `ActivityIndicator size="small" color="#FF5C1A"`
- Per D-12: if no row exists on first load, show UI with defaults immediately (no spinner required for that case — UPSERT runs in background).

### OS Settings denied CTA card (when `notifDenied = true`)

Reuse existing card exactly from settings.tsx lines 98-127:
- `borderRadius: 12, backgroundColor: '#FFFFFF', marginBottom: 12`
- Shadow: `shadowOpacity: 0.06, shadowRadius: 8, elevation: 2`
- Left icon: `notifications-off-outline` size 20, color `#FF5C1A`
- Right chevron: `chevron-forward-outline` size 16, color `#6B6963`
- `Linking.openSettings()` on press

## Interaction Contract

### Master switch (push_enabled)

| State | Visual | Behavior |
|-------|--------|----------|
| ON | STRow toggle active (#FF5C1A track) | Category rows active at opacity 1.0; quiet hours section visible |
| OFF | STRow toggle inactive (grey track) | Category rows visible but `opacity: 0.4`, `pointerEvents: 'none'`; quiet hours section hidden (conditional render) |
| Toggle | Immediate local state update | 600ms debounce → Supabase UPSERT |

### Category toggles (5 rows)

| State | Visual | Behavior |
|-------|--------|----------|
| Enabled, master ON | Full opacity, toggle active/inactive per value | Tappable; debounced save |
| Any value, master OFF | opacity: 0.4 on row wrapper, non-interactive | pointerEvents: 'none' — visual state preserved, not hidden |

### Quiet hours pickers

| Trigger | Row label | Right text | Picker items |
|---------|-----------|------------|--------------|
| `quiet_hours_start` | "De" | e.g. "22h00" | "0h00" … "23h00" (24 items, id = string of integer 0–23) |
| `quiet_hours_end` | "À" | e.g. "7h00" | "0h00" … "23h00" (24 items) |

- Tapping the row opens the corresponding `InlinePicker` bottom sheet
- Selection: immediate local state update → 600ms debounce → Supabase UPSERT
- InlinePicker item padding: `paddingVertical: 12` (multiple of 4)
- InlinePicker selected item: `fontWeight: '700'` + `#FF5C1A` checkmark icon
- Hour display format in row `right` prop: `"${hour}h00"` (e.g. "22h00", "7h00")

### Auto-save pattern

```
onToggle / onSelect
  → setS(next)           ← immediate (no lag)
  → clearTimeout(saveRef.current)
  → saveRef.current = setTimeout(async () => {
      await supabase.from('notification_preferences').upsert(
        { user_id, ...fullState, timezone_offset },
        { onConflict: 'user_id' }
      )
    }, 600)
```

No save button. No success toast. Silent persistence. Source: D-09 in CONTEXT.md.

### Mount sequence

1. `Notifications.getPermissionsAsync()` → set `notifDenied`
2. UPSERT defaults with `ignoreDuplicates: true` (D-08)
3. SELECT `notification_preferences` WHERE `user_id` (D-11)
4. If row found: apply to local state, `setIsLoading(false)`
5. If no row (first time): show defaults immediately, UPSERT already handled in step 2

## States Inventory

| State | Trigger | Visual Contract |
|-------|---------|-----------------|
| Loading | Mount, prefs fetch pending | STHeader + centered ActivityIndicator (#FF5C1A) |
| Default / normal | Prefs loaded | Full screen with all sections |
| Permission denied | `status === 'denied' && !canAskAgain` | OS Settings CTA card above master switch group |
| Master OFF | `push_enabled = false` | Category rows at opacity 0.4 + non-interactive; quiet hours section hidden |
| Master ON | `push_enabled = true` | All rows interactive; quiet hours section visible |
| Picker open | User taps "De" or "À" row | InlinePicker bottom sheet modal (fade animation, semi-opaque backdrop `rgba(0,0,0,0.4)`) |
| Saving | 600ms after any change | No visual indicator — silent |
