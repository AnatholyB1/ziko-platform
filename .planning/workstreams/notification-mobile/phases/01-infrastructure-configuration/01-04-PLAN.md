<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| EAS build system | google-services.json injected as file secret — never travels through git |
| Developer machine → Expo Push API playground | Manual test push uses token value from DB — not a secret, tokens are single-use-keyed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | google-services.json in EAS secrets | mitigate | EAS file secrets are encrypted at rest; file never committed to git; CI build workers access it via EAS-managed injection |
| T-04-02 | Tampering | APNs p8 key revocation | mitigate | Use `eas credentials` only — never revoke keys manually in Apple Developer portal without rotating first |
| T-04-03 | Spoofing | FCM MismatchSenderId | mitigate | google-services.json and EAS FCM credential must come from the same Firebase project — verify Sender ID matches during credential setup in Task 1 |
</threat_model>
