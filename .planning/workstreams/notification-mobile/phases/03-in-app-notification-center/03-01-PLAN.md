    Export as: export const useNotificationStore = create<NotificationState>()(...)

    Note: This store intentionally has no userId in state — callers pass userId to syncUnreadCount. Store is initialized with unreadCount: 0.

    Category-to-NotifItem mapping helpers (defined as internal constants, not exported):

    CATEGORY_ICON map (NotificationRow.category → Ionicons glyph):
    - 'coach' → 'sparkles-outline'
    - 'workout' → 'fitness-outline'
    - 'gamification' → 'ribbon-outline'
    - 'health' → 'water-outline'
    - 'system' → 'notifications-outline'

    CATEGORY_TINT map (NotificationRow.category → hex color):
    - 'coach' → '#7B5BD0'
    - 'workout' → '#FF5C1A'
    - 'gamification' → '#E8A33A'
    - 'health' → '#2E9E5B'
    - 'system' → '#2E7BF6'

    CATEGORY_CAT map (NotificationRow.category → NotifItem.cat):
    - 'coach' → 'coach'
    - 'workout' → 'reminder'
    - 'gamification' → 'achievement'
    - 'health' → 'reminder'
    - 'system' → 'reminder'

    toRelativeTime(isoString: string): string — converts ISO timestamp to French relative string:
    - < 1 min → "À l'instant"
    - < 60 min → "Il y a X min"
    - < 24 h → "Il y a X h"
    - yesterday → "Hier · HH:MM" (using toLocaleTimeString with 'fr-FR')
    - > 1 day → "Il y a X j"

    toGroup(isoString: string): 'today' | 'earlier' — compares created_at date (UTC) to today's UTC date (new Date().toDateString()). If same date → 'today', else → 'earlier'.

    mapRow(row: NotificationRow): NotifItem — maps a NotificationRow to NotifItem shape using the maps above plus toRelativeTime and toGroup. Sets unread: row.read_at === null, url: row.data?.url.

    Export useNotifications hook:
    function useNotifications(userId: string | undefined)

    Inside:
    1. queryClient = useQueryClient()
    2. Query: useQuery<NotificationRow[]>({ queryKey: ['notifications', userId], enabled: !!userId, staleTime: 30_000, queryFn: async () => { fetch from notification_log WHERE user_id = userId ORDER BY created_at DESC LIMIT 50; } })
    3. After query data resolves: derive unreadCount from data.filter(r => r.read_at === null).length and call useNotificationStore.getState().setUnreadCount(unreadCount)
    4. Expose items: data?.map(mapRow) ?? [] (already sorted by created_at DESC from query)

    markRead mutation:
    - useMutation({ mutationFn: async (notificationId: string) => { UPDATE notification_log SET read_at = new Date().toISOString() WHERE id = notificationId via supabase.from('notification_log').update({ read_at: new Date().toISOString() }).eq('id', notificationId) }, onSuccess: () => { queryClient.invalidateQueries({ queryKey: ['notifications', userId] }) } })

    markAllRead mutation:
    - useMutation({ mutationFn: async () => { supabase.from('notification_log').update({ read_at: new Date().toISOString() }).eq('user_id', userId!).is('read_at', null) }, onSuccess: () => { queryClient.invalidateQueries({ queryKey: ['notifications', userId] }) } })

    Return: { items, isLoading, unreadCount, markRead: markRead.mutate, markAllRead: markAllRead.mutate }

    Where unreadCount is derived from data (not from the store — keep in sync with query data).

    IMPORTANT: After both mutations succeed, also call useNotificationStore.getState().setUnreadCount(newCount) where newCount is derived from the updated cache (in onSuccess, compute from updated data or set to 0 for markAllRead).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mobile Supabase client → notification_log | User-scoped client; RLS enforces auth.uid() = user_id |
| mobile → setBadgeCountAsync | OS badge count — client-computed from unread count |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | notification_log SELECT | mitigate | RLS policy "notification_log_read" (USING auth.uid() = user_id) prevents cross-user reads; no additional code required |
| T-03-02 | Tampering | notification_log UPDATE (mark read) | mitigate | RLS policy "notification_log_mark_read" (USING + WITH CHECK auth.uid() = user_id) prevents marking other users' notifications as read |
| T-03-03 | Denial of Service | Badge count setUnreadCount called on every query | accept | Count derived from already-fetched data; no extra DB query; setBadgeCountAsync is fire-and-forget |
</threat_model>
