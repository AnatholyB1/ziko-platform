Workstream `activation-inscrit`, milestone v1.21. Source : `02-CONTEXT.md` (D-01..D-08), `design/02-DESIGN-CONTRACT.md`. Aucun changement backend ni migration.

## Faits du code relevés
- Coût / solde / quota gratuit : `GET /ai/workshop/info` (`cost` = `CREDIT_COSTS.chat`, `balance`, `free_left`). `/ai/session/generate` (IA simple) et l'atelier passent tous deux par `creditCheck('chat')` : une seule source serveur pour les deux chemins IA, sans appel nouveau côté backend. Le contrat suppose un quota mensuel « programme » pour IA simple : faux dans le code, le quota est quotidien (libellé `gratuite aujourd'hui`).
- Séances terminées : `ziko_workout_sessions.ended_at` (colonne confirmée, déjà lue par `useWeeklySessions`). On compte `ended_at` non nul ET séance comptable (`COUNTABLE_SESSION_OR_FILTER`) pour qu'une séance vide fermée ne masque pas la carte.
- Écran d'épuisement existant : `useCreditStore.showExhaustionSheet` (monté dans le layout racine, déjà utilisé par l'atelier).
