# Milestone v1.15: Custom Widget Dashboards

**Workstream:** `custom-widget`
**Status:** ✅ SHIPPED 2026-05-28
**Phases:** 01–04
**Total Plans:** 19

## Overview

This milestone delivered a per-athlete customizable dashboard to the coach CRM. A coach opens the Dashboard tab on any client detail page, sees a default set of 7 widget types rendered with live athlete data, then enters AI edit mode where a split-screen chat with Claude reshapes the dashboard in natural language. The entire customize-to-save flow completes in under 30 seconds. Templates and preferences persist in `coach_memory` so future dashboards start from the coach's established defaults.

## Milestone Summary

**Key Decisions:**
- Closed widget set (hard enum) — Zod discriminated union rejects unknown types at schema level
- `schema_version: 1` from day 1 to avoid painful production retrofits
- Atomic tool execution — preview only updates from `part.state === output-available` (not streaming partial JSON)
- Array order for layout, not integer position field — simpler schema
- Multi-turn spike on day 1 of Phase 03 — two-turn test must pass before any plan is marked complete
- `/memory` route registered before `/:clientId` in Hono to prevent routing ambiguity
- `stopWhen: stepCountIs(2)` for dashboard edit (not 5 — tools are fast, 2 steps is sufficient)

**Tech Debt:**
- `DEFAULT_WIDGETS` widget IDs generated once at module load (now unused in new-pair path)
- `TemplateNamingModal` does not invalidate `['coach-memory']` TanStack Query cache after save
- `DashboardEmptyState` called without `prompt` prop in `page.tsx` — generic message when `sport === null`
- No VERIFICATION.md files for any of the 4 phases (verification done via inline SUMMARY self-checks)
- `DELETE /coach/dashboards/:clientId` route has no frontend caller (orphaned)

**Issues Resolved:**
- Phase 01 ↔ Phase 04 contract disagreement on "new dashboard" — fixed post-audit (getDashboardConfig returns `[]`, TemplatePicker auto-skips when no templates)

**Issues Deferred:**
- Dashboard sharing between coaches
- PDF export per-athlete view (web already has PDF export for coach own dashboard)
- Widget comments/annotations
- Mobile read-only view of coach dashboard
