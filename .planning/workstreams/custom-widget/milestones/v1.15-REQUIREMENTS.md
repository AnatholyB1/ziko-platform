## v1 Requirements

### Dashboard Core (DASH)

- [x] **DASH-01**: Coach can view a full-screen dashboard tab on each client detail page — ✓ v1.15 (Phase 02)
- [x] **DASH-02**: Dashboard loads a default config on first access for a coach+athlete pair — ✓ v1.15 (Phase 01+02; new-pair detection fixed post-audit)
- [x] **DASH-03**: Coach can drag and resize widgets to reorder the layout (react-grid-layout, locked in view mode) — ✓ v1.15 (Phase 02)
- [x] **DASH-04**: Dashboard config persists per coach+athlete pair in Supabase — ✓ v1.15 (Phase 01)

### Widgets — Closed Set of 7 Types (WIDGET)

- [x] **WIDGET-01**: Line chart — time series, configurable dataKey and period — ✓ v1.15 (Phase 02)
- [x] **WIDGET-02**: Bar chart — aggregated metric by period — ✓ v1.15 (Phase 02)
- [x] **WIDGET-03**: KPI tile — single metric with trend indicator — ✓ v1.15 (Phase 02)
- [x] **WIDGET-04**: Table — list of recent sessions/entries — ✓ v1.15 (Phase 02)
- [x] **WIDGET-05**: Athlete list — coach's linked athletes with last activity date — ✓ v1.15 (Phase 02)
- [x] **WIDGET-06**: Threshold indicator — metric vs target, color-coded — ✓ v1.15 (Phase 02)
- [x] **WIDGET-07**: Callout — free-text note added by coach — ✓ v1.15 (Phase 02)

### AI Edit Session (EDIT)

- [x] **EDIT-01**: Coach can enter edit mode: split-screen (dashboard preview left + chat right) — ✓ v1.15 (Phase 03)
- [x] **EDIT-02**: Coach types in chat → Claude calls tools (add/update/remove/reorder widget) → live preview updates — ✓ v1.15 (Phase 03)
- [x] **EDIT-03**: Changes visible in preview before any save action — ✓ v1.15 (Phase 03)
- [x] **EDIT-04**: Coach can save (persist to Supabase) or cancel (discard preview) — ✓ v1.15 (Phase 03)
- [x] **EDIT-05**: Edit chat restricted to dashboard tools only — no general coaching questions in this session — ✓ v1.15 (Phase 03)

### Coach Memory (MEM)

- [x] **MEM-01**: Coach can save current dashboard as a reusable template; available for next athlete — ✓ v1.15 (Phase 04; apply path fixed post-audit: getDashboardConfig returns [] for new pairs)
- [x] **MEM-02**: Coach's widget preferences (defaults) persist for future dashboards — ✓ v1.15 (Phase 04)

### Infrastructure (INFRA)

- [x] **INFRA-01**: Migration 056: `dashboard_configs` + `coach_memory` tables with RLS — ✓ v1.15 (Phase 01)
- [x] **INFRA-02a**: Hono bounded context `coach/dashboards/` — 5 CRUD routes — ✓ v1.15 (Phase 01)
- [x] **INFRA-02b**: `POST /coach/dashboards/:clientId/ai-edit` — SSE endpoint for Claude dashboard tools — ✓ v1.15 (Phase 03)
- [x] **INFRA-03**: `GET /coach/clients/:clientId/widget-data` — aggregates athlete data per widget type with period scoping — ✓ v1.15 (Phase 01)
- [x] **INFRA-04**: Zod discriminated union strict (`additionalProperties: false`) + `schema_version: 1` from day one — ✓ v1.15 (Phase 01)

## Out of Scope (Confirmed)

- Vocal input (covered by workstream `retour-vocal`)
- Custom widget types / infinite extensibility
- Node-based / graph editor
- Color pickers, drag-onto-empty-canvas flows (anti-feature for 30s criterion)
- Auto-save (explicit "Sauvegarder" action required)
- General coaching chat in the edit session (separate chat route)
