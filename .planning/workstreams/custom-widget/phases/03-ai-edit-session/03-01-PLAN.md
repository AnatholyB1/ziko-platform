  <behavior>
    - applyAddWidget(widgets, input): clones widgets array, generates a new UUID id for the widget if input.id is absent, calls WidgetSchema.parse(input) to validate, pushes the validated widget, returns the new array
    - applyUpdateWidget(widgets, { id, config }): finds the widget by id, merges config via spread (shallow merge on the config sub-object only — not the full widget), returns new array with the updated widget; throws Error("Widget not found: {id}") if id absent
    - applyRemoveWidget(widgets, { id }): returns new array with the widget matching id filtered out; returns unchanged array if id not found (no throw — idempotent)
    - applyReorderWidgets(widgets, { ids }): reorders by the explicit ids array — `ids.map(id => widgets.find(w => w.id === id)).filter(Boolean)`; widgets NOT in the ids list are dropped (the ids array is the canonical new order)
    - Each function is pure (no side effects, does not mutate the input array)
    - PITFALLS compliance: additionalProperties: false already enforced by WidgetSchema.strict() — no raw JSON accepted
  </behavior>
