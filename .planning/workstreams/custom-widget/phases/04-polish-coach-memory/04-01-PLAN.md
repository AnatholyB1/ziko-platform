<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→API (PUT /memory) | Coach sends partial memory update; backend must merge safely without replacing unrelated fields |
| coach_memory JSONB | Templates array can grow unbounded; server should not validate/limit size in this phase (best-effort) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | PUT /memory body | mitigate | Server reads only known fields (preferences, templates, recent_actions); unknown keys in body are ignored during merge |
| T-04-02 | Information Disclosure | GET /memory response | accept | Only coach's own row returned — authMiddleware + RLS enforce coach_id = auth.uid() at DB level |
| T-04-03 | Elevation of Privilege | PUT /memory — overwriting another coach's memory | mitigate | authMiddleware sets userId from JWT; upsertCoachMemory always uses userId from auth context, never from request body |
| T-04-04 | Denial of Service | Templates array unbounded growth | accept | No size limit this phase; coach can only write their own row; attack surface is low-value |
| T-04-05 | Tampering | MEM-02 fire-and-forget fetch in browser | accept | Fire-and-forget is best-effort; auth token from existing session, no new surface; silent fail means no error leakage |
| T-04-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages in this plan — no install tasks |
</threat_model>
