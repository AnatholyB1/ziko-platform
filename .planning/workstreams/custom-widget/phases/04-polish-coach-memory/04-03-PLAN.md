    **handleApply async function:**
    1. `setApplyingId(template.id)`
    2. `await fetch('/api/coach/dashboards/' + clientId, { method: 'PUT', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ widgets: template.widgets }) })`
    3. On success: trigger GSAP exit (per UI-SPEC Motion section 4):
       ```
       gsap.to(pickerContainerRef.current, { opacity: 0, duration: 0.15, ease: 'power2.in', onComplete: () => onSelect(template.widgets) })
       ```
    4. On error: `setApplyingId(null)` (reset state, no toast for now)

    **handleSkip function:**
    Same GSAP exit, onComplete calls `onSkip()`:
    ```
    gsap.to(pickerContainerRef.current, { opacity: 0, duration: 0.15, ease: 'power2.in', onComplete: () => onSkip() })
    ```
