Make the founders page findable from anywhere on the site and measurable once it converts: a plain
nav link in the header and another in the footer, an entry in the sitemap so search engines can find
it at all, and a single cookieless conversion event so the growth question this milestone exists to

reachable. ENTRY-06 is the difference between a launch and a measured launch. All three are small,
and all three are the kind of small thing that is silently skipped and noticed a month later when
someone asks how the offer performed.

Output: two nav links threaded through the existing server/client layout split, one sitemap entry,
one analytics mount, one guarded event call, and three suites pinning them.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| every page of the site → the new nav links | The header and footer render on every route including the authenticated coach application, so anything added here is on every page for every audience. |
| visitor's browser → analytics endpoint | A third-party-hosted collection endpoint now receives an event when a signup completes. Whatever the payload carries leaves the first-party boundary. |
| sitemap and robots output → search crawlers | What is listed here is what gets indexed. What is listed here wrongly gets indexed wrongly, at scale, and slowly. |
