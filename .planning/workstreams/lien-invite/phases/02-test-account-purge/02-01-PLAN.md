<objective>
Build the read-only half of the purge: one thin path that runs end to end from environment
configuration through the Supabase Auth Admin API, through the locked `@ziko-app.com` criterion and
the cross-link exclusion, out to a report file a human can review. This is the artifact PURGE-01 and
PURGE-02 are about — the concrete row set, on disk, with nothing deleted.

Purpose: `research/PITFALLS.md` Pitfall 13 names "no dry run" as the single most common cause of
over-deletion incidents, and names ambiguous criteria as the second. Both are addressed here, before
any script capable of deleting anything exists in the repo at all.

Output: `scripts/purge-test-accounts/lib.mjs`, `scripts/purge-test-accounts/dry-run.mjs`, a
git-ignored export directory, and a Vitest suite that drives the whole pipeline through injected
fakes so it is provable without production credentials.
</objective>
