## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| any client key → PostgREST | The anon and authenticated keys reach `app_config` and the new functions directly; deny-all plus explicit grants are the only control |
| Server Action / Route Handler → Postgres | The counter's exact value crosses this boundary only when the database has decided it may |
| operator → `reset_waitlist_founder_sequence` | A privileged call that can re-mint founder ranks |
