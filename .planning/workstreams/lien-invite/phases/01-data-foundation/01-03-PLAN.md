## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anon key → PostgREST | The publishable key is shipped to every browser; whatever it can reach is public |
| authenticated session → PostgREST | A logged-in athlete or coach is still an untrusted party with respect to the waitlist |
| test runner → Supabase project | A DB-mutating spec pointed at the wrong project is itself an attack on the data |
